# カード制御の敵 現行仕様

> 更新日: 2026-11-23
> 提案全体と未実装部分は `proposed-enemy-card-ai-and-character-stats.md` を参照。
> 本文書は実装済み部分の正本。

## 0. 行動予測の考え方

- 敵のターン開始時に、敵の行動（カード選択・コスト支払い・ドロー等）を実際に一度行い、
  その結果として「行う予定の戦場効果」を記録する（反映はしない）。これが行動予測。
- 頭上には記録から「何回・いくつの攻撃」「いくつの防御」「バフ・デバフの有無」を表示する。
- 敵の行動時は、記録した予定をそのまま再現して実行する。予測と実行で別の判断はしない
  （ただし攻撃力・筋力等の数値は実行時の有効値。予測表示も現在値で随時更新される）。

## 1. 定義

- 埋め込みの敵 34 体は全てカード制御（`deck`）。旧 Move 方式も読み込み互換として残る。
  `deck` と `moves` / `initialMoveId` の同時指定は不可。
- カード制御の敵の項目（Unit と同じ形式）:

| 項目 | 既定値 | 意味 |
|---|---|---|
| `deck` | — | `[{ cardId, count?, upgraded?, priority? }]`。通常行動デッキ |
| `aiProfileId` | 必須 | 現在は `low_cost_combo` のみ |
| `initialEnergy` | 0 | 戦闘開始時のエナジー |
| `energyPerTurn` | 1 | ターン開始時の加算量（上限なし・持越し） |
| `drawPerTurn` | 3 | ターン開始時のドロー枚数 |
| `handLimit` | 5 | 手札上限 |
| `attack` | 0 | 基礎攻撃力（筋力とは別） |
| `defense` | 0 | 基礎守備力（敏捷とは別） |
| `openingActions` | なし | 先制行動のカード ID 配列（§7） |

- 敵用カードは `src/Core/Data/Cards/enemy_*.json`（レアリティ Token、報酬・収集対象外）。
  - 共通: `enemy_common_attack`（通常攻撃: コスト1、全体に「自身の攻撃力」アタック）、
    `enemy_common_defend`（通常防御: コスト1、自身に「自身の守備力」ブロック）。
  - 固有: `enemy_<敵ID>_<旧MoveID>`（旧 Move の効果をそのまま 1 枚化、コスト1）。
- 現段階では、選択（`select: "choose"`）効果と `summon` を含むカードは敵デッキに入れられない
  （整合性検証エラー）。

## 2. 戦闘中の状態

- 敵ごとのカード資源は `BattleState.EnemyParticipants`（`BattleParticipantState`）に持つ。
  味方の `Participants` とは別で、Ready 同期・人間コマンド・root ミラーには参加しない。
- 予約した戦場効果は `CombatActor.PlannedEffects`（使用順、使用時に AmountSource 確定済み）。

## 3. ターンの流れ

1. 戦闘開始時（第 1 ターン開始処理と `OnBattleStart` の後）および各ターン開始処理の後、
   味方 CPU とプレイヤーより先に、カード制御の敵が Slot 順に以下を行う。
   1. 前ターンの手札整理（待機以外は捨札）、コンボ・ターン限定状態のリセット
      （味方参加者と同じ規則 `ApplyTurnEndToProjectedRoot` / `ResetAtTurnStart`）。
   2. エナジーに `energyPerTurn` を加算（上限なし）。
   3. `drawPerTurn` 枚ドロー（山札不足時は捨札を再構築）。
   4. 行動計画（下記 §4）。
2. プレイヤー・味方の行動中、敵の予約は **予測のみ**。ブロック・バフ・デバフ・攻撃は未適用。
3. プレイヤー攻撃の後、敵の行動時（`EnemyAttackingResolver`）に予約を実行し、`PlannedEffects` を空にする。

## 4. 行動計画

カードの選び方（優先順位）は味方CPUと共通: [current-cpu-card-play-policy.md](current-cpu-card-play-policy.md)。

- 次の 1 枚は味方 CPU と同じ `CpuCardPlayPolicy` の比較規則で選ぶ
  （コンボ軽減継続 → 継続 → 途切れ → 実支払コスト → deck の priority → 手札左）。
  使用可能なカードがなくなるまで続け、1 体 1 ターン 30 枚を安全上限とする。
- カード使用は通常のカード処理を共通利用する: 使用回数、使用制限、コスト計算、エナジー支払い、
  コンボ・Wild、カード移動（廃棄・待機・捨札）。
- 予約時に即時処理する効果: ドロー、捨て、廃棄、強化、エナジー獲得、コスト変更、カード追加・回収など
  手札・山札・資源系。対象は敵自身のみ。
- 予約する戦場効果: `attack` / `block` / `buff` / `debuff` / `heal` / `selfDamage` / `summon`。
- 敵カードでは特性・レリック・パワー・有事・再演は発火しない。

## 5. 実行

- 予約は「非攻撃効果（使用順）→ 攻撃効果（使用順）」の順で実行する。
  後から使ったバフも攻撃前に反映される。
- 攻撃は旧 Move 敵と同じ解決（1 効果ごとに即時ヒット、Single は行動開始時の最小 Slot の生存味方、
  途中死亡で残りは不発、Random は毎回抽選、All は生存者全員、追撃・有事・反射等も同じ）。
- ブロックは旧 Move 敵と同じく行動時に得て、次のプレイヤー攻撃で消費、次の自分の行動前にリセット
  （堅牢で持越し）。
- 発生源 `CombatSource` はカード（`CardEffect`、カード ID・インスタンス ID・効果 index）。

## 6. 行動予告

- `CombatIntentProjector` は `PlannedEffects` を実行順に並べて予告する。
  攻撃値は筋力・脱力・元気等を live 反映し、予約済みの自己バフも攻撃予告に含める。
  ブロックは予定値、バフ・デバフ・回復はアイコンで表示する。

## 7. 初期行動（先制行動。2026-11-28 改訂）

- `openingActions` のカードは通常デッキ・手札・捨札・エナジー・コンボと独立する。使ったカードはどの山にも入らない（除外とも違い、そもそも山に加わらない）。
- タイミング: 戦闘開始時、第 1 ターンの開始処理（手札を配る・特性・有事・`OnTurnStart`）と `OnBattleStart` がすべて終わった後、
  プレイヤーが操作を始める直前。順番は **敵の初期行動（Slot 順・記載順）→ 味方の初期行動 → 敵の 1 ターン目の行動予約 → プレイヤーの操作**。
- 敵の初期行動は、通常の敵の行動と同じ処理（`EnemyAttackingResolver`）でその場で実行する。通常行動・汎用行動・固有行動・初期行動用のカードのどれでも、何枚でも設定できる（攻撃も可）。
- 味方側: プレイヤーキャラの定義（`Data/Characters/*.json`）にも `openingActions` を書ける（今は未設定）。そのキャラが使ったものとして効果を実行し、攻撃はほかのカードと同じく予約されてターン終了時に当たる。
- 画面: 戦闘開始の演出の中で、使ったキャラの頭上にカード名を出す（「敵のターン」の帯は出さない）。
- 今の設定: ダーク・カルティストの「詠唱」（筋力 3）。

## 8. 能力値（攻撃力・守備力）

- プレイヤー（キャラクター JSON）・CPU 味方（Unit JSON）・敵がそれぞれ `attack` / `defense` の
  初期値を持つ（既定 0）。戦闘中は `CombatActor.AttackPower` / `DefensePower`。
- 筋力・敏捷とは別の値。カード効果は `amountSource: "selfAttack"` / `"selfDefense"` で参照し、
  効果量＝能力値（攻撃力 0 なら 0）。そこへ従来どおり筋力・脱力・元気（攻撃）、敏捷（ブロック）が加わる。
- `amountScalePercent`（%）で倍率を掛けられる（切り捨て）。例: 強攻撃＝攻撃力の 150%。
  筋力等は倍率を掛けた後に加わる。`amountSource` 無しでは指定不可。
- カード文面の表示:
  - 使用者が分からない場面（図鑑・カタログ・デッキ一覧）: 「X(Xは自身の攻撃力)」「X(Xは自身の攻撃力×1.5)」（`[V:X|ラベル]`）。
  - 使用者が分かる場面（戦闘中の手札・行動再生）: formatter は `[R:値|up/down/空:ラベル]` を出す。
    カード面は具体値（筋力等の上振れ・下振れ色付き）、カーソルを合わせたポップアップでは
    「X(Xは自身の攻撃力)」と参照元を表示し、固定値カードと見分けられるようにする。
- 敵の予約では能力値参照を固定せず、行動実行時の有効値で確定する（予告は現在値で表示）。
  プレイヤー・CPU 味方は既存 AmountSource と同じく使用時に評価する
  （戦闘中に攻撃力・守備力そのものを変える効果は未実装のため、現状は実行時と同値）。
- 永続補正（レリック・イベント等）・一時補正は未実装（提案書 §5）。

## 9. 自動生成した初期データ（2026-11-23、後から手動調整する前提）

旧 Move 定義から次の規則で生成した。

- 攻撃力＝旧 Move の攻撃効果の最小値、守備力＝ブロック効果の最小値（無ければ攻撃力の半分切り捨て）。
- 固有カードを旧 Move 1 つにつき 2 枚、残りを通常攻撃:通常防御＝2:1 で補充して 12 枚。
- `initialEnergy` 0、`energyPerTurn` 1、`drawPerTurn` 3、`handLimit` 5（全カード コスト1 のため
  1 ターン 1 行動。旧 Move と同じ頻度で、行動順はデッキのシャッフル順になる）。

### 9.1 行動デッキの原則（2026-11-28）

- 行動デッキは原則 10 枚。ドローとエナジーは同じ数（行動数）: 雑魚（通常の弱・強）= 1、強敵（エリート）・ボス = 2。
- 行動するカードはすべて 1 コスト。0 コストは行動数を増やすドローカード（臨戦態勢）だけ。
- 固有行動の種類は、雑魚 1 種・強敵 2 種・ボス 3 種。残りは通常行動（コモン）と汎用行動（レア）。

| 区分 | 固有行動 | 通常攻撃 | 通常防御 | 臨戦態勢 | 汎用行動（1 種） |
|---|---|---|---|---|---|
| 雑魚（弱） | 1 種 ×2 | ×4 | ×2 | — | ×2 |
| 雑魚（強） | 1 種 ×2 | ×3 | ×2 | ×1 | ×2 |
| 強敵 | 2 種 ×2 | ×3 | ×1 | — | ×2 |
| ボス | 3 種 ×2 | ×2 | ×1 | — | ×1 |

汎用行動は敵ごとに、外した固有行動の役割に近いものを選んだ（強攻撃・強防御・連続攻撃・筋力強化・脱力付与）。
固有行動のうちデッキから外したカード（30 枚）はデータとして残してある（`enemy_cave_bat_a_bite` など。再び使う時はデッキに戻すだけ）。

## 10. プレイヤー・味方の能力値と初期デッキ（2026-11-23）

| キャラ | 攻撃力 | 守備力 |
|---|---|---|
| 残光剣士セラ（ストライカー） | 6 | 5 |
| ガーディアン | 5 | 6 |
| タクティシャン | 5 | 5 |
| エンハンサー | 5 | 5 |
| ウィスプ（CPU 味方） | 3 | 3 |

- 初期カード「攻撃の基本」「防御の基本」は能力値参照に変更済み
  （攻撃の基本＝攻撃力、強化で 150%／防御の基本＝守備力、強化で 160%。旧固定値 6→9 / 5→8 と同等）。
- 2026-11-25: この 2 枚はクラスごとのカードに分けた（`<class>_basic_attack` / `<class>_basic_defense`、
  class = striker / guardian / tactician / enhancer、所属はそのクラス）。効果は同じで、初期デッキの枠がクラスの枠で統一される。
  旧共通の `basic_attack` / `basic_defense` は初期・報酬の枠から外し（poolKinds 空）、古いセーブの読み込み用に残している。
- 共通行動カード「強攻撃」`enemy_common_heavy_attack`（コスト2、全体に攻撃力の 150%）。
  現在どの敵デッキにも未投入（デッキ調整時に使用）。
- 注意: `data-local/dev-overrides/`（git 管理外のローカル上書き）はキャラ・ユニット定義を丸ごと置き換える。
  新しい項目（`attack` 等）を追加した時は上書きファイル側にも反映が必要。

## 11. 敵の行動再生（開発確認用）

- 敵の計画（ターン開始時のカード使用）は味方CPUと同じ行動記録（`CpuCommittedAction`）として
  `BattleState.EnemyPlanningActions` に残り、Server が行動ジャーナルへ追加する。
- 戦闘画面の敵の頭上（行動予告と対象▼の間）の「行動」ボタンから、そのターンに使ったカードと予定（攻撃・ブロック）を再生できる。
- 再生中は画面右上（捨札・除外と同じ右端の列の最上部）に × ボタンを出し、「戻る」と同じく再生を閉じる。
- 再生パネルの行動表示は ◀ ▶ でページ送りでき、そのターンの全カードを確認できる（停止中のみ）。
  内部注記（`remaining=N`）は「コンボゲージ+1（合計 N）」のように読める文に変換する。
- 再生中は味方の再生と同様に、プレイヤーUI（手札・山札・捨札・除外・エナジー）を同じ位置のまま敵のカード資源に切り替える。
  そのため行動記録の前後状態（`stateBefore`/`stateAfter`）にだけ、その敵参加者を `participants` に含める。
- 敵表示中は UI を敵用の装飾（赤黒のビネット・発光）に切り替え、「敵の行動 ― 敵名」を表示する。
  戦技・奥義を持たない参加者の表示中は戦技・奥義 UI を出さない。READY も隠す。
- 状態 DTO（ライブ）の `enemyParticipants` は敵のカード資源の概要（エナジー・各領域の枚数）だけを公開し、手札の中身は出さない。
- 敵の計画はターン開始時に完結するため、各敵の最後の記録で再生フィードを完了（COMPLETE）にする。
- 敵の計画イベントはライブのイベント列には流さない（予測であり、演出は再生で確認する）。
- 製品版で見せるかは未定。

## 12. 能力値の表示（2026-11-23）

- 操作キャラ・味方・敵はすべて HP・攻撃力・守備力・ドロー(枚数)・エナジー(ターン開始時の規定値) を持つ（2026-11-28 に 体力・知力・行動力 から改名）。
- 戦闘中、キャラにカーソルを合わせると「キャラ名(操作アカウント)」の見出しで、HP（上限）・攻撃力/守備力・ドロー/エナジー（ターン開始時に回復する数）を、項目名の後ろに半角スペースと黄色の数字で表示する。続けて特性名（戦技・奥義の名前と同じ見出しの書式）と特性の効果、位相（あれば）。
- アーカイブスのキャラクター一覧、キャラクター選択画面、モンスター図鑑（ツールチップ）で 5 項目を表示する
  （クライアント共通コンポーネント `ActorStats`、1 行 1 項目。キャラ選択とアーカイブスで同じ表示）。
- 値が届いていない場合は 0 ではなく「—」と表示する（古いサーバーとの組み合わせで誤った 0 を出さない）。
- アーカイブスの特性欄は、戦技・奥義と同じ書式付き文面（`traitEffects`）でキーワード補足を表示する。
- アーカイブスのモンスター欄はプレイヤーキャラと同じ枠で、能力値・生息地（`act`）・ポジション（`tier`:
  通常（弱）/通常（強）/エリート/ボス）・キャラクター説明（敵 JSON の任意項目 `description`）・
  初期行動（`openingActions`）・行動デッキを表示する。デッキ欄は押すとカード一覧（キャラ選択と共通の
  `DeckListModal`）を開く。

## 13. 敵の行動時の演出（2026-11-24）

- 敵が予約したカードを実行する時、カードが切り替わるたびに `EnemyCardAction` イベント（CardId = カード定義 ID）を出す。
  実行順は「非攻撃 → 攻撃」なので、バフと攻撃を持つカードは名前が 2 回出ることがある。
- 画面は敵の頭上（行動ボタンの上）にカード名の札を約 1.4 秒表示し、読める間（650ms）を取ってから効果を再生する。
- バフ・デバフ・ブロック・回復を受けたキャラは、種類ごとの色で光る（足元からの光柱＋リング＋スプライト発光）。
  敵が起こしたものは発光を見せるため少し長く待つ（320ms）。味方側の同種の効果にも同じ発光を出す。
- 攻撃ヒットの演出グループは `EnemyCardAction` で区切る（次の敵の行動を前の攻撃に吸収しない）。
