# CPU のカード使用ルール（`low_cost_combo`）

> 現行仕様（2026-11-24 時点の実装 `CpuCardPlayPolicy` / `BattleCpuPlanningCoordinator` /
> `EnemyCardPlanner` から明文化）。味方CPU（ウィスプ等）とカード制御の敵は**同じ判断ロジック**を使う。
> AI プロファイルは現在 `low_cost_combo` の 1 種類のみ。

## 1. 全体の流れ

1. 手札の中から「今使えるカード」を全部挙げる（§2）。
2. その中から優先順位（§3）で **1 枚だけ** 選んで使う。
3. 使った結果（エナジー・コンボ・手札の変化）を反映してから、また 1 に戻る。
4. 使えるカードが 1 枚も無くなったら終了（Ready）。

- **使えるカードは全部使う。** エナジーを意図的に温存したり、カードを手札に残したりはしない。
- **先読みはしない。** 毎回「今の時点で一番良い 1 枚」を選ぶ貪欲法で、
  「この順番で使えばコンボが一番長くなる」という全体最適の計算はしない。
- **カードの効果の中身は見ない。** 攻撃かブロックか、ダメージ量、相手のHPや予告などは
  選択に影響しない（例外: 単体攻撃の対象選び §5）。

## 2. 「使えるカード」の条件

次を全て満たす手札だけが候補になる。

- カード定義がある。
- そのカードの「1ターンの使用回数上限」に達していない。
- 使用制限の状態異常で禁止されていない（呪縛・束縛・沈黙など）。
- コンボゲージ消費があるカードは、ゲージが足りている。
- **実際に払うコスト**（コンボ軽減・コスト変化・節制/浪費などを反映した値）が、現在のエナジー以下。

## 3. 候補の優先順位（上ほど優先）

| 順位 | 比較項目 | 優先される側 |
|---|---|---|
| 1 | コンボの継続 | ① コンボが続き、しかもコンボ軽減（-1）を受ける → ② コンボは続くが軽減なし → ③ コンボが途切れる |
| 2 | 実際に払うコスト | 安い方 |
| 3 | デッキ定義の `priority` | 大きい方（未指定は 0） |
| 4 | 手札の位置 | 左（手札の先頭）の方 |

- つまり **「コンボを最大限つなぐ → 安いカード → priority → 左から」** の順。
- コンボが途切れるカードしか無い時も、使えるなら使う（③でも使う）。

### コンボの判定（参考）

- **通常の継続**: 直前に使ったカードの**元コスト + 1** の元コストのカード（0→1→2→3…）。
  この場合はコンボ軽減（支払 -1）も受ける。
- **ワイルド／スーパーワイルド**: コンボ中なら継続扱い（ワイルドはコンボ中 1 回まで）。
- **次カード保護**（ワイルドの効果等）・**継続**（状態）・**連環**の持ち越しも継続扱い。
- **コンボ 0 の最初の 1 枚は「継続」扱いにならない**（③ と同列で、2〜4 の順で選ばれる）。

## 4. 選択を伴うカード

- 「手札から 1 枚捨てる」等の選択が出たら、**候補の先頭から必要枚数**を自動で選ぶ（左から）。
- カード制御の敵のデッキには、選択を伴うカード・召喚カードを入れられない（データ検証で拒否）。

## 5. 対象の選び方

### 味方CPU
- 単体攻撃を含むカード: 次の順で敵を選ぶ。
  1. そのカードの単体攻撃で**倒せる**敵
  2. **HPが少ない**敵
  3. **Slot が小さい**（左の）敵
- 単体攻撃を含まないカード: 生きている最初の敵。

### 敵
- 計画時には対象を決めない。行動の実行時に、現行ルール（**生きている味方のうち Slot が最小**）で決める。
- 全体・ランダム攻撃はスコープどおり。

## 6. 安全上限・停止条件

- 1キャラ 1ターン **30 行動**、CPU全体（味方）で **100 行動** まで。
- 同じ状態に戻った（無限ループ）と判定したら停止。
- 行動できるキャラがいなくなった（死亡等）時も停止。

## 7. 敵だけの事情

- 敵はターン開始時に、自分のカード資源（山札・手札・捨札・エナジー）で上の手順を**実際に行い**、
  戦場効果は予約（予告表示）にして、敵の行動時にその順で再現する（[current-enemy-card-ai-spec.md](current-enemy-card-ai-spec.md)）。
- 現在の自動生成データは「初期エナジー 0、毎ターン +1、ドロー 3（手札上限 5）、全カード コスト 1」。
  そのため **1 ターンに使えるのは基本 1 枚**（使い残したエナジーは持ち越すが、毎ターン使い切るので
  2 枚使う状況はほぼ起きない）。2 回行動させたい敵は、エナジー回復量・初期エナジー・コスト 0 カード等で調整する。
- 敵・味方ユニットのデッキは現在どれも `priority` を指定していない（すべて 0）。
  そのため §3 の 3 は実質効いておらず、同条件なら手札の左から使う。

## 8. 現状やっていないこと（今後プロファイルを増やす時の候補）

- 効果の価値の比較（攻撃と防御のどちらが得か、致死ダメージを優先、HPが減ったら防御 など）。
- 先読みによるコンボ順の最適化、エナジー・カードの温存。
- 戦技・奥義・ポーションの自動使用（味方CPUでも未使用）。
