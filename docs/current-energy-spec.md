# 現行エナジー仕様

> 更新日: 2026-08-10  
> 本文書は Phase 10 時点の旧設計書より優先する。

## ターン開始時

- 未使用の `Energy` は次のターンへ持ち越す。
- ターン開始時に、現在の `Energy` へ `EnergyMax` を加える。
- `EnergyMax` は互換性のため残している名前で、現在の意味は「ターン開始時の追加量」。エナジーの保有上限ではない。
- API / Client では誤読を避けるため、この値を `energyPerTurn` として公開する。
- 基本のターン開始時追加量は 3。レリック等による `energyPerTurnBonus` はこの値を増やす。
- ゲーム上の保有上限は設けない。長期持越しでも符号反転しないよう、ターン加算・`gainEnergy`・`gainMaxEnergy` は `int.MaxValue` で飽和する。
- `OnTurnStart` のレリック・パワー効果は、基本のターン開始時加算とドローの後に処理する。

## 戦闘開始・終了

- 戦闘開始時の初期値は `Energy = 0`。その直後に第1ターンの開始処理を行うため、通常は `0 + 3 = 3` で操作を開始する。
- ターン終了処理では `Energy` を消去しない。敵行動と手札整理の後、次ターン開始処理で追加量を加える。
- プレイヤーまたは敵の死亡により次ターン開始前に戦闘が決着した場合、次ターン分は加えない。
- ターン開始時の毒などで戦闘が決着した場合も、エナジー加算とドローを行わない。
- すでに `Outcome` が確定済み、または `Phase=Resolved` の状態へターン開始処理が呼ばれた場合は、ターン番号・エナジー・手札を含めて何も変更しない。

## 手札との関係

- エナジーの持越しだけを変更する。ターン終了時の手札整理と、次ターン開始時のドロー処理は従来どおり。
- 待機対象でない手札は捨て札へ送り、待機対象は残したうえで規定枚数をドローする。
