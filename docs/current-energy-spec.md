# 現行エナジー仕様

> 更新日: 2026-11-27（ターン開始時を「規定値まで回復」に変更）
> 本文書は Phase 10 時点の旧設計書より優先する。

## ターン開始時

- ターン開始時、`Energy` が規定値（`EnergyMax`）に満たなければ規定値まで回復する。
  規定値以上残っていれば、増えも減りもせずそのまま持ち越す（`EnergyMath.RefillTo`）。
  - 例（規定値 3）: 残り 0 → 3、残り 1 → 3、残り 3 → 3、残り 5 → 5。
  - 2026-11-26 までは「残り＋規定値」の加算だった。ターンを重ねるほど過剰に増えるため変更した。
- `EnergyMax` は互換性のため残している名前で、意味は「ターン開始時の回復の規定値」。保有上限ではない（規定値を超えて持てる）。
- API / Client では誤読を避けるため、この値を `energyPerTurn` として公開する。エナジー表示は「現在値/規定値」（例「1/3」）。
- 基本の規定値は 3。キャラごとの値と、レリック等による `energyPerTurnBonus`・`gainMaxEnergy` がこの値を増やす。
- ゲーム上の保有上限は設けない。長期持越しでも符号反転しないよう、`gainEnergy`・`gainMaxEnergy` は `int.MaxValue` で飽和する。
- 加速（ターン開始時のエナジー回復量+X）と消耗（ターン開始時にエナジーをX失う）は、規定値までの回復の**後**に足し引きする。
  先に足すと回復に吸収されてしまうため（例: 残り 1・規定値 3・加速 2 → 3 まで回復してから +2 で 5）。
- `OnTurnStart` のレリック・パワー効果は、回復とドローの後に処理する。
- 主人公・味方 CPU（参加者）・カード制御の敵のすべてに同じ規則を使う。

## 戦闘開始・終了

- 戦闘開始時の初期値は `Energy = 0`。その直後に第1ターンの開始処理を行うため、通常は規定値（3）で操作を開始する。
- ターン終了処理では `Energy` を消去しない。`OnTurnEnd` で得たエナジーも残りに含め、次ターン開始時に規定値と比べる。
- プレイヤーまたは敵の死亡により次ターン開始前に戦闘が決着した場合、次ターンの回復は行わない。
- ターン開始時の毒などで戦闘が決着した場合も、エナジー回復とドローを行わない。
- すでに `Outcome` が確定済み、または `Phase=Resolved` の状態へターン開始処理が呼ばれた場合は、ターン番号・エナジー・手札を含めて何も変更しない。

## 手札との関係

- ターン終了時の手札整理と、次ターン開始時のドロー処理はエナジーと独立している。
- 待機対象（と、静の持ち主の双極付きカード）は残し、それ以外の手札は捨て札へ送ったうえで規定枚数をドローする。
