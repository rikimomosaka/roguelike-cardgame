# 残光剣士セラ（Striker）

> キャラクター設定とデザイン指示。ゲーム内 ID は従来どおり `default`（セーブ互換のため変更しない）。
> 出典: クラス設計 [current-striker-class-concept-v2.md](../../current-striker-class-concept-v2.md) の案「残光剣士セラ」。

## 設定

- 名前: セラ　／　肩書き: 残光剣士　／　クラス: ストライカー（前衛単体火力）
- 年齢・性格: 18 歳前後。口数は少なく、判断が速い。一度決めた攻撃の順番は迷わず斬り切る。
- 流派「残光流」: 斬撃の軌跡に光の残り火（残光）を刻み、決めの一太刀（終撃）のあと、その軌跡をもう一度なぞって斬る剣術。
  ゲームの「連携（コストの階段）→ 終撃 → 残光で再実行」をそのまま剣術として表したもの。
- 来歴: 光を刻む剣を受け継いだばかりの若い剣士。まだ残光を長く留められず、それを補うために正確な連撃の順番を磨いてきた。
- ゲーム内の説明文: 「0、1、2、3コストの攻撃列を組み、終撃で連撃を締め、残光でその軌跡をもう一度なぞる剣士。」

## デザイン指示（AI 生成用の共通要素）

- シルエット: 細身・軽装の剣士。高い位置のポニーテール、短いマント、片手持ちの細身の片刃剣。前傾ぎみの構え。
- 配色（クラス色の赤 #d9533f を主に）:
  - 髪: 銀白（毛先にわずかに赤橙の光）
  - 服: 濃紺の上着＋赤のマント・襟の差し色、黒のブーツ・手甲
  - 剣: 銀の刀身、振った跡に赤橙〜金の光の筋（残光）
- 目: 赤橙。表情は落ち着いて鋭い。
- 避けること: 重装鎧・大剣・盾（ガーディアンと被る）、紫や緑の主色（エンハンサー・タクティシャンの色）。

## 生成記録

### バトル立ち絵（2026-11-25 採用）

確立した手順（PixelLab の生成回数を使わない）:

1. **原画**: ChatGPT で全身コンセプトアートを作る（1024×1536、背景 #00FF00 単色）。
   最初の原画（約 7 頭身）を、同じ会話で「約 3.5 頭身のデフォルメ体型で描き直して」と依頼して `concept_02.png` を得た。
   **等身は原画の段階で決める**（PixelLab の init 画像経由でも等身はほぼ変わらない）。
2. **背景除去**: `tools/art-pipeline/key.mjs`（緑の除去と縁の緑かぶり補正）。
3. **縮小**: `tools/art-pipeline/fit.mjs --w 80 --h 80 --margin 2`（面積平均、アルファ二値化、足元揃え）。
4. **減色**: `tools/art-pipeline/quantize.mjs --colors 24`（k-means、ディザなし）→ `base.png`。
5. **目閉じ差分**: 目の画素（80px 上で左右それぞれ 2〜3px）を手で肌色＋閉じ線に置き換えて `blink.png` を作った。
   PixelLab の edit-image では目が閉じず、色数も増えたため不採用。
6. **待機**: `tools/art-pipeline/idle.mjs --cut 44 --sway 13,4,34,40` で 8 フレームを作る（呼吸 1px、まばたき 1 フレーム、ポニーテールは呼吸の 1 フレーム後に揺らす）。
   ×3 の整数倍拡大で現行の 192×256 シートへ配置する。

比較のため試した案（不採用）:

- 文章だけの生成（pixflux / pixen）: 等身が高く、顔がリアル寄りになった。
- 原画を init にした PixelLab 再生成（strength 150/300）: 絵としては整うが、原画をそのまま縮小・減色した版の方が良かった。

作業ファイルは `art-work/sera/`（git 管理外）にある。
attack / hurt は仮のもの（基本画像の平行移動と赤フラッシュ）で、PixelLab のアニメーション生成で置き換える予定。
