# ミレイユ・ユノ・リラ の戦闘スプライトとアイコン（2026-11-28 作り直し・現行）

> 対象: 鉄衛騎士ミレイユ（`guardian_mireille`）、作戦参謀ユノ（`tactician_yuno`）、調律師リラ（`enhancer_lyra`）。
> 規格と作り方はセラ（[striker_sera.md](striker_sera.md)）と同じ。前日の PixelLab だけで作った版（[heroes-rebuild-2026-11-27.md](heroes-rebuild-2026-11-27.md)）は、
> 顔つきがセラと違ったため置き換えた。
> 作業ファイルは `art-work/heroes3/`、原画は `art-work/<mireille|yuno|lyra>/`（どちらも git 管理外）。

## 原画（ChatGPT、ユーザーが生成）

1. セラと同じ書式のプロンプトで全身の原画を作った（1024×1536）。添付画像は 2 枚。
   - セラの原画（画風・顔つき・等身の見本）
   - 旧立ち絵（デザインの見本）
2. 1 回目（`concept_01.png`）は 6〜7 頭身になった。セラのときと同じく「約 3.5 頭身のデフォルメ体型で描き直して」と頼み、`concept_02.png` を得た。
   - 描き直しは ChatGPT の利用枠が切れたため、別の AI で行った（ユーザー作業）。
   - 背景は 3 枚ともマゼンタ（#FF00FF）になった。ユノは緑の服なので、マゼンタを指定していた。
3. 原画で決まったこと:
   - リラの杖の先は竪琴（リラ）の形。
   - リラの髪の水色のメッシュは描き直しで消えた。

## 手順

1. **背景抜き**: `key.mjs --color flood`。
   - 四隅から背景色を測り、外周からつながった背景色に近い画素だけを消す。
   - リラの紫の服はマゼンタに近いので、色だけで判定する方式では服まで消えてしまう。そのため、この方式を追加した。
2. **縮小・減色**: `fit.mjs --w 80 --h 80 --margin 2` → `quantize.mjs --colors 24`。
   - 高さはセラと同じ 76 ドット。
   - `art-work/heroes2/prep.mjs` で、128×96 のモーション用キャンバスを作る。
3. **目閉じ**: セラと同じく、目の上側を肌色にし、下の段に閉じ線を引いた（`art-work/heroes3/blink.mjs`）。
4. **待機**: `idle.mjs`。
   - 上下させる最下行（`--cut`）: ミレイユ 44、ユノ 46、リラ 42。
   - 髪の揺れ（`--sway`）: ミレイユ 15,6〜28,36、リラ 12,20〜22,54。
5. **モーション**: PixelLab `animate-with-text-v3` → `motion.mjs`。
   - 採用の一覧は `art-work/heroes3/picks.json`、仕上げは `finalize.mjs`。
   - 被弾はセラと同じ作り（1 コマ目は赤フラッシュ、後ろへ 0,-2,-3,-1 ずらす）。
6. **キャラ選択アイコン（120×160、48 色）**: 原画から頭〜太ももを 3:4 で切り出し、`fit.mjs` → `quantize.mjs --colors 48`。PixelLab は使っていない。
   - ユノとリラは原画の頭が大きいので、切り出しを 1.18 倍に広げて、セラと同じ構図にした（`art-work/heroes3/crop.mjs`）。
7. **初期カードのイラスト**: 「攻撃の基本」は attack の 3 コマ目、「防御の基本」は guard の 4 コマ目を合成し直した。

## モーションの内容と採用

| モーション | ミレイユ | ユノ | リラ |
|---|---|---|---|
| attack | 剣を後ろから前へ横に振る | 弩を前に向けて撃つ | 杖を突き出し、先に光の輪 |
| attack_alt | 盾で押す（シード 2） | 弩を肩に構えて撃つ | 杖を振り下ろす |
| skill（奥義） | 剣を掲げて青い光、振り下ろす | 弩の先に緑の光、光る矢を撃つ | 杖を掲げ、光を放つ |
| guard | 盾を体の前に構えて身をかがめる | 弩を下げ、腕で顔をかばって身をかがめる | 杖を引き寄せて身構える |
| cast | 剣を顔の前に立て、刀身に青い光 | 矢筒から矢を取って装填する | 杖を立て、先が紫に光る |
| hurt / down | のけぞる（シード 2）／倒れる | 同左 | 同左 |

### 処理を足したもの・やり直したもの

ユノは、80 ドットだと弩が弓に見えやすい。そのため PixelLab は「弓を引く」動きを描きがちだった。
- 「a crossbow, NOT a bow」と明記して作り直し、弩を水平に構えた案を採った。
- その案は白い閃光が付いたので、`--drop-white 40` で消した。肌が一番白い色でも白から 42 離れているので、肌は残る。顔の画素に欠けが無いことは確認済み。
- 防御は、最初は弩を顔の前に掲げる形にしたが「武器を構えていて防御に見えない」とのことで、弩を下げて腕でかばう形に作り直した（`guard_r6`、白い線は `--drop-white 40` で消した）。

その他:
- ミレイユ: 防御は 2 回目で採用（1 回目は白い閃光）。
- リラ: 振り下ろしの白い弧を `--drop-white 10` で消した。

PixelLab の消費: 70 回分（1,726 → 1,656）。
