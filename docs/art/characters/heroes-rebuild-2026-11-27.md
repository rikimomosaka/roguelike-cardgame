> 対象: 鉄衛騎士ミレイユ（`guardian_mireille`）、作戦参謀ユノ（`tactician_yuno`）、調律師リラ（`enhancer_lyra`）。
> 規格はセラ（[striker_sera.md](striker_sera.md)）と同じ。旧素材（192×256 のコマを縮小した仮の絵）は置き換えた。
> 作業ファイルは `art-work/heroes2/`（git 管理外）。

## デザインの元

旧立ち絵（384×512 の胸から上の絵、今は git の履歴にだけ残る）の髪・服・色・武器を引き継いだ。

| キャラ | 主な特徴 | 武器 |
|---|---|---|
| ミレイユ | 金髪の高いポニーテールに青いリボン、銀の板金鎧に金の縁、青いスカーフとマント | 片手剣と、白い鷲の紋章の青い凧形盾 |
| ユノ | ぼさぼさの濃緑の髪、緑の目、金の刺繍の濃緑の立ち襟コート、背中に矢筒 | 木製の弩（クロスボウ） |
| リラ | 銀白の長い波打つ髪に三つ編みと紫の大きなリボン、紫と白のドレス、紫の宝石飾り | 先が金の音叉になった長い杖 |

## 手順

セラの原画は ChatGPT で描いたが、今回は使えないため PixelLab だけで作った。

1. **基本の絵（80×80、24 色）**: PixelLab `generate-image-v2`（`pixellab.mjs gen2`）。
   - 見本画像: 旧立ち絵を「デザインの見本」、セラの `base.png` を「画風・等身の見本」（style_image）として渡す。
   - 指示文: 約 3.5 頭身、右向きの斜め、戦闘の構え、透明背景、エフェクトなし。`target_palette` で 24 色。
   - 1 回で 9 案が出る（15 回分）。ミレイユは 6 番、ユノは 3 番、リラは 3 番を採用。
   - `art-work/heroes2/prep.mjs` で足元 77 行・横中心に置き直し、128×96 のモーション用キャンバス（左 24・上 16 の余白）も作る。
2. **目閉じ（blink.png）**: セラと同じく、目の上側を肌色にして下の段に閉じ線を引いた（手作業の画素指定、`blink.mjs`）。
3. **待機**: `idle.mjs`（呼吸 1px・まばたき 1 コマ）。
   - 上下させる最下行（`--cut`）: ミレイユ 48、ユノ 52、リラ 46。
   - 髪の揺れ（`--sway`）: ミレイユはポニーテール（18,4〜33,32）、リラは長い髪（8,16〜21,58）。ユノは無し。
4. **モーション**: PixelLab `animate-with-text-v3` → `motion.mjs`（基本パレットへ寄せる、浮いたエフェクトを消す）。
   - 被弾は、1 コマ目を基本画像の赤フラッシュにして、生成の 2〜4 コマ目を続け、後ろへ 0,-2,-3,-1 ずらす（セラと同じ作り）。
   - 採用の一覧は `art-work/heroes2/picks.json`、仕上げは `finalize.mjs`（原寸シートと character.json を出力）。
5. **キャラ選択アイコン（120×160、48 色）**: `generate-image-v2` で、旧立ち絵とその戦闘スプライトをデザインの見本、セラのアイコンを画風の見本にした。
   ミレイユ 1 番、ユノ 0 番、リラ 0 番を採用。
6. **初期カードのイラスト**: 「攻撃の基本」は attack の 3 コマ目、「防御の基本」は guard の 4 コマ目に差し替えた（`card-art-prompts.mjs`）。背景は前のまま。

## モーションの内容

| モーション | ミレイユ | ユノ | リラ |
|---|---|---|---|
| attack | 剣を後ろから前へ横に振る | 弩を構えて撃つ | 杖を突き出し、先に紫の光 |
| attack_alt | 盾を前へ押し出す | 狙いを定めて撃つ（銃口に小さな光） | 杖を振り下ろす |
| skill（奥義） | 剣を掲げて青い光をため、振り下ろす | 弩の先に緑の光をため、光る矢を撃つ | 杖を高く掲げ、紫の光の輪を放つ |
| guard | 盾を掲げて受ける | 弩を胸の前に構えて受ける | 杖を体に引き寄せて身構える |
| cast | 剣を顔の前に立て、刀身に青い光 | 矢筒から矢を取って装填する | 杖を立て、音叉の先が紫に光る |
| hurt / down | のけぞる／ひざをついて倒れる | のけぞる／倒れる | のけぞる／倒れる |

## やり直したもの（記録）

「character only, no effects」と書いても、白い閃光・星・輪などのエフェクトが体に重なって出ることが多かった。
体に接したエフェクトは `--main-only` では消せないので、シード違いを生成して、エフェクトの無い案を選んだ。

- ミレイユの attack / attack_alt / hurt: 3 回目（シード 2〜4）で採用。被弾は「hit / struck」と書くと衝撃のエフェクトが出るので、「押されたように後ろへ」と言い換えた。
- ユノの attack_alt / guard / skill / hurt: 2〜3 回目で採用。skill は 1 回目で途中から弩が弓に変わった。
  採用案も 6・7 コマ目で体が薄い緑に変色したので、5・8 コマ目で差し替えた。
- リラの attack_alt / guard: 2 回目で採用。guard の 1 回目は杖を突き出して攻撃に見えた。attack_alt の白い弧は `--drop-white 10` で消した。

PixelLab の消費: 合計 161 回分（1,887 → 1,726）。
