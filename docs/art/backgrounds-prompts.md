# 背景の原画プロンプト（ChatGPT 用・画像の添付なしで使う）

> 規格: [current-art-asset-spec.md](../current-art-asset-spec.md) §4.6。生成した画像は `art-work/` に置き、
> PNG にしてから `art/source/backgrounds/<種類>/<id>.png` に入れ、`node tools/art-pipeline/build-assets.mjs` で縮小・減色する。
> 演出（光・粒・霧）は `src/Client/src/components/ambient/ambientScenes.ts` に足し、`?dev=scenes` で位置を合わせる。

## 共通の書き方

どの背景も次の【画風】と【禁止】を入れる。
- 【画風】ざらつき防止（2026-11-28 のマップ作り直しで効果があった）＋奥行きと描き込み（2026-11-28、Gemini で泉を作ったら平板でチープになったため追加）。
- チープに見えないための決まり（2026-11-28、Gemini の泉・図書館が平板・左右対称で安っぽくなったため）:
  - 構図は少し斜め・左右非対称。主役は中央からわずかにずらす。手前の隅に暗い影の物（柱・岩・木の幹など）を大きく入れて奥行きを出す。
  - 「古さ・使われた跡」などの細部を具体的に並べる（散らばった物、ひび、苔、蜘蛛の巣など）。
  - 光源は 2 つ以上にして色の対比を付け、光の当たる所と闇に沈む所をはっきり分ける。
  - ドットの細かさは「横 480 ドット程度」と数で書く（「1 ドットがはっきり見える粗さ」と書くと粗く平板になる）。
  - 「同じ色の面をまとめて塗る」「点描禁止」は強く書かない（平板になる）。禁止するのは画面全体のノイズだけ。
- 【禁止】画面の使われ方（文章・ボタン・UI が重なる等）は書かない。書くと絵の中にボタンや枠を描いてしまう（Gemini で発生）。
  下を暗くしたい時は「手前は木々の影で暗い」のように、絵の中身の言葉で書く。

```
【画風】横 480 ドット程度の細かさで描いた、緻密なピクセルアートの背景画。1 ドットごとに丁寧に置き、石・木肌・葉などの質感まで描き込む。光と影のグラデーションには控えめなディザ（市松の点々）を使ってよいが、画面全体を覆うノイズやざらつきにはしない。手前・中景・奥で奥行きを出し、光のにじみや霞も描く。
【禁止】文字・ロゴ・ボタン・枠・縁取り・角丸・周りの暗い縁（ビネット）・UI は描かない。画像の四辺の端まで絵を描き切る。人物・動物は描かない（指定がある場合を除く）。既存の作品に似せない。
```

用途ごとの違い:

| 用途 | 比率 | 書き添えること |
|---|---|---|
| マップ | 横長 16:9 | 主役を置かず静かな風景、コントラスト低め。中央下から奥へ道が伸びる一点透視 |
| 戦闘 | 横長 16:9 | 下 45% は平らな地面（キャラが左右に立つ）。地面には物を置かない。奥の景色は画面の上半分 |
| イベント | 横長 3:2 | 主役（泉・本棚・商人など）は中央からやや上。手前（下 3 分の 1）は影で暗く、物を置かない。（UI のことは書かない） |

## マップ（2026-11-28 採用）

第 1 幕（森）・第 2 幕（洞窟）・第 3 幕（地獄）。本文は会話ログのとおり。要点:
場面（道と両脇の木・岩）、雰囲気、色（コントラスト低め）、【画風】、構図（16:9、中央下から奥へ道）、人物・文字なし。

## Gemini で作る時のこと（2026-11-28）

- 画面下の比率は 3:2 が無ければ 16:9 で作る（こちらで上下を切って 3:2 にする。主役が中央にあれば問題ない）。
- ボタンや枠が出た時は、同じ会話で「下にある四角いボタンと、周りの黒い縁を消して、画像の端まで背景を描いて」と頼む。
- 平板に見える時は、同じ会話で「手前・中景・奥の奥行きと、光のにじみ・霞をもっと描き込んで。色はそのまま」と頼む。

## イベント（作り直し）

### 祝福の泉 `blessing_fountain`

```
ゲームの背景用の、横長のピクセルアート（ドット絵）を1枚描いてください。

【場面】森の奥に忘れられた、古い石造りの泉。苔むした丸い石の水盤に澄んだ水がたまり、奥の崩れかけた小さなアーチから細い水が流れ落ちている。周りに折れて倒れた石柱が数本、蔦に覆われている。頭上の木々の切れ間から、泉へ斜めに光の筋が差し込み、光の中に花粉や小さな光の粒が浮かぶ。
【古さの描写】水盤の縁の欠け、石畳の隙間から生えた草、根に持ち上げられて傾いた敷石、水面に浮かぶ落ち葉。
【光】木漏れ日（淡い黄緑）と、水面の照り返し（水色）の 2 つ。光の当たる泉と、周りの森の暗がりをはっきり分ける。
【雰囲気】静かで清らか。神聖だが派手すぎない。
【色】深い緑と青緑を中心に、水面の水色と、差し込む光の淡い黄緑。画面全体を明るくしすぎない。
【画風】横 480 ドット程度の細かさで描いた、緻密なピクセルアートの背景画。1 ドットごとに丁寧に置き、石・木肌・葉などの質感まで描き込む。光と影のグラデーションには控えめなディザ（市松の点々）を使ってよいが、画面全体を覆うノイズやざらつきにはしない。手前・中景・奥で奥行きを出し、光のにじみや霞も描く。
【構図】横長 3:2。少し斜めから見下ろす、左右非対称の構図。泉は中央からわずかに左上。右手前の隅に、暗い影になった太い木の幹と根を大きく入れて奥行きを出す。画面の下 3 分の 1 は木々の影の多い草地（小さな青い花が点々とある程度）。
【禁止】文字・ロゴ・ボタン・枠・縁取り・角丸・周りの暗い縁（ビネット）・UI は描かない。画像の四辺の端まで絵を描き切る。人物・動物は描かない。既存の作品に似せない。
```

### 古の図書館 `old_library`

```
ゲームの背景用の、横長のピクセルアート（ドット絵）を1枚描いてください。

【場面】何十年も閉ざされていた石造りの大図書館。左右の壁一面に高い本棚と、2 階の回廊。奥の壁の縦長のステンドグラスの窓から、青白い月明かりが斜めに床へ差し込み、光の中に埃が浮かんでいる。窓から少し右にずれた位置に古い木の机があり、開いたままの分厚い本と、溶けかけたろうそくの燭台が 1 つ灯っている。
【古さの描写】本棚の所々が抜け落ち、床に本や紙が散らばっている。倒れた椅子、天井の隅の蜘蛛の巣、床石のひび割れ、壁を這う蔦、2 階の手すりの一部が崩れている。
【光】月明かり（青白い）とろうそく（暖かい橙）の 2 つの光源。月明かりの筋は床に四角い光だまりを作り、ろうそくは机の周りだけを暖かく照らす。本棚の奥は闇に沈む。
【雰囲気】静かで少し不思議。忘れられた知識の場所。
【色】暗い焦げ茶と紺を中心に、月明かりの青白と、ろうそくの橙を少しだけ。
【画風】横 480 ドット程度の細かさで描いた、緻密なピクセルアートの背景画。1 ドットごとに丁寧に置き、石・木肌・葉などの質感まで描き込む。光と影のグラデーションには控えめなディザ（市松の点々）を使ってよいが、画面全体を覆うノイズやざらつきにはしない。手前・中景・奥で奥行きを出し、光のにじみや霞も描く。
【構図】横長 3:2。少しだけ斜めから見た、左右非対称の構図。窓と机は中央からわずかに右。左手前の隅に、暗い影になった太い石柱と積み上げた本を大きく入れて奥行きを出す。画面の下 3 分の 1 は影の多い床（散らばった紙が少し見える程度）。
【禁止】文字・ロゴ・ボタン・枠・縁取り・角丸・周りの暗い縁（ビネット）・UI は描かない。本の背表紙にも文字は書かない。画像の四辺の端まで絵を描き切る。人物・動物は描かない。既存の作品に似せない。
```

### 怪しげな商人 `shady_merchant`

```
ゲームの背景用の、横長のピクセルアート（ドット絵）を1枚描いてください。

【場面】洞窟の奥に構えた、布張りの小さな露店。継ぎはぎの紫の布の天幕、吊るされた形の違うランタンが 3 つ。使い込まれた木の台の上に、怪しく光る小瓶、錆びた短剣、青い宝玉、骨の飾り、紐で縛った巻物、天秤が雑多に並ぶ。台の奥に、深くフードをかぶった商人が座り、顔は影で見えない。片手を台の上の青い宝玉へ差し出している。
【細部】天幕から吊るされた干した薬草や小さな袋、台の脇に積まれた木箱と壺、地面に敷いた擦り切れた絨毯。
【光】ランタンの暖かい橙と、宝玉・小瓶の青紫の 2 種類。商人の顔と洞窟の奥は闇に沈む。
【雰囲気】怪しいが、敵意はない。取引の誘い。
【色】暗い紫と焦げ茶を中心に、ランタンの暖かい橙と、宝玉・小瓶の青紫を少しだけ。
【画風】横 480 ドット程度の細かさで描いた、緻密なピクセルアートの背景画。1 ドットごとに丁寧に置き、石・木肌・葉などの質感まで描き込む。光と影のグラデーションには控えめなディザ（市松の点々）を使ってよいが、画面全体を覆うノイズやざらつきにはしない。手前・中景・奥で奥行きを出し、光のにじみや霞も描く。
```
