# 背景の原画プロンプト（ChatGPT 用・画像の添付なしで使う）

> 規格: [current-art-asset-spec.md](../current-art-asset-spec.md) §4.6。生成した画像は `art-work/` に置き、
> PNG にしてから `art/source/backgrounds/<種類>/<id>.png` に入れ、`node tools/art-pipeline/build-assets.mjs` で縮小・減色する。
> 演出（光・粒・霧）は `src/Client/src/components/ambient/ambientScenes.ts` に足し、`?dev=scenes` で位置を合わせる。

## 共通の書き方

どの背景も次の【画風】を入れる（ざらつき防止。2026-11-28 のマップ作り直しで効果があった）。

```
【画風】16bit 時代の RPG のような、くっきりしたドット絵。1 ドットがはっきり見える粗さで、ノイズのような細かい点描やざらつきは入れない。色数は少なめ（多くて 64 色程度）で、同じ色の面をまとまりとして塗る。グラデーションは段階的なドットで表す。
```

用途ごとの違い:

| 用途 | 比率 | 書き添えること |
|---|---|---|
| マップ | 横長 16:9 | 上に地図が重なる。主役を置かず静かな風景、コントラスト低め。中央下から奥へ道が伸びる一点透視 |
| 戦闘 | 横長 16:9 | 下 45% は平らな地面（キャラが左右に立つ）。地面には物を置かない。奥の景色は画面の上半分 |
| イベント | 横長 3:2 | 上に文章、下に選択肢が重なる。主役（泉・本棚・商人など）は中央からやや上、画面の下 3 分の 1 は暗めで落ち着かせる |

## マップ（2026-11-28 採用）

第 1 幕（森）・第 2 幕（洞窟）・第 3 幕（地獄）。本文は会話ログのとおり。要点:
場面（道と両脇の木・岩）、雰囲気、色（コントラスト低め）、【画風】、構図（16:9、中央下から奥へ道）、人物・文字なし。

## イベント（作り直し）

### 祝福の泉 `blessing_fountain`

```
ゲームの背景用の、横長のピクセルアート（ドット絵）を1枚描いてください。

【用途】ローグライクカードゲームのイベント画面の背景。上に文章、下に選択肢のボタンが重なる。主役は中央からやや上に置き、画面の下 3 分の 1 は暗めで落ち着かせる。
【場面】森の奥の、古い石造りの泉。苔むした丸い石の水盤に澄んだ水がたまり、奥の小さなアーチから細い水が流れ落ちている。周りに折れた石柱が数本。頭上の木々の切れ間から、泉へまっすぐ光が差し込んでいる。足元に青い小さな花が点々と咲く。
【雰囲気】静かで清らか。神聖だが派手すぎない。
【色】深い緑と青緑を中心に、水面の水色と、差し込む光の淡い黄緑。画面全体を明るくしすぎない。
【画風】16bit 時代の RPG のような、くっきりしたドット絵。1 ドットがはっきり見える粗さで、ノイズのような細かい点描やざらつきは入れない。色数は少なめ（多くて 64 色程度）で、同じ色の面をまとまりとして塗る。グラデーションは段階的なドットで表す。
【構図】横長 3:2。泉を中央に、正面からやや見下ろす。左右は木々で囲む。
【その他】人物・動物・文字・枠・UI は入れない。既存の作品に似せない。
```

