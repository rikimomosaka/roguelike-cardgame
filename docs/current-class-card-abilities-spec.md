# カード能力（キーワード） 現行仕様

> 更新日: 2026-11-27
> カードに付くキーワード能力の現行の要約。ゲーム内の説明文は `src/Core/Cards/CardKeywords.cs`（クライアントは `CardDesc.tsx` の `KEYWORD_DEFS`）が正。
> 細かい処理順・境界のケースは、採用されて実装済みの提案書 [archive/proposed-class-exclusive-abilities-v2.md](archive/proposed-class-exclusive-abilities-v2.md) の該当節を参照する。
> 食い違いがあれば実装（テスト）が正。
> バフ・デバフ（残光・堅持・護衛・守勢・攪乱・連環・余韻・共鳴など）は [current-battle-status-spec.md](current-battle-status-spec.md)。
> 位相・双極・エンハンス・反転は [current-phase-spec.md](current-phase-spec.md)。

能力そのものはクラス制限なし（配布上の方針として、主に使うクラスを決めているだけ）。

## 1. コンボを続けるもの

| キーワード | ID | ゲーム内の説明 |
|---|---|---|
| ワイルド | `wild` | このカード及び次に使うカードではコンボが途切れない。このコンボ中、以降のワイルドを無効にする。 |
| スーパーワイルド | `superwild` | このカード及び次に使うカードではコンボが途切れない。 |

- コンボの規則そのものは [current-combo-spec.md](current-combo-spec.md)。

## 2. カードの行き先

| キーワード | ID | ゲーム内の説明 |
|---|---|---|
| 待機 | `wait` | 手札にある限り、次のターンに持ち越される。 |

## 3. 条件付き効果

### 乗勢X（`maxComboMin`、キーワード表示 `momentum`）

> 効果の実行時、自身のこのターンの最大コンボがX以上であれば適用される。

- 判定に使うのは現在コンボではなく、そのキャラ（参加者）の**このターンの最大コンボ**。
- そのカード自身で最大コンボが X に届いた場合も成立する。終撃でコンボが 0 に戻っても、最大コンボは残るので成立し続ける。
- カード面では「乗勢3：敵単体に6アタック。」のように、条件と効果を同じ行に書く。
- 残光・再演で効果を再実行するときは、その時点の最大コンボで判定し直す。
- 詳細: アーカイブ §2.1。

## 4. ストライカーの攻撃列

### 終撃（`abilities: finisher`）

> 効果の適用後、このカードを含むこのコンボ中の全てのアタックカードを保存し、現在コンボを0にする。

- 現在コンボは必ず 0 に戻る。最大コンボと、すでに得たコンボゲージは維持する。
- 保存した攻撃列（終撃記録）は、残光（バフ）が自身の攻撃終了時に再実行する対象になる（残光の規則は [current-battle-status-spec.md](current-battle-status-spec.md)）。
  同じターンに複数回終撃したら、最後の記録で上書きする。記録はターン終了時に消える。
- 詳細: アーカイブ §2.2（終撃）・§2.3（残光）。

### 再演（`abilities: reprise`）

> 再演条件を満たし、この戦闘中に最後に効果の解決を完了した自身のカード1枚の効果を再実行する。

- 再実行するのは効果だけ。コスト支払い・使用回数・コンボ判定・位相の使用時判定は行わない。
- 対象の条件（元コスト・種類など）はカードごとの再演条件で決める。
- 詳細: アーカイブ §2.4。

## 5. タクティシャンの伏策

### 伏策（`abilities: contingency`）

> 使用時は効果が実行されず、発動待ちとして除外する。伏策条件を満たした時に効果を実行し、捨札へ移動する。

- 使用（コスト支払い・コンボ判定）は使った時点で行う。効果は条件を満たした時に実行する。
- 演出（2026-11-28）: 使った時は、カードの種類に関わらず使ったキャラが発動モーション（cast）をする。
  発動した時は、カードが除外から画面中央へ出て、縁が光り、輪が広がり、「伏策発動」の判子と発動条件（ターン開始時／相手の攻撃時／コンボ達成時）を見せる。
  判子がカードの本文を隠すので、判子の中に発動した効果（説明文の伏策条件の行より後）を転記する。
  続けて、仕込んだキャラが効果に合わせて動く（攻撃を得る = attack、ブロックを得る = guard、それ以外 = cast。その場で攻撃が当たる時は攻撃の演出に任せる）。
- 発動条件の種類（相手のアタック時・コンボ到達時など）はカードごとに指定する。
- 詳細: アーカイブ §4.2。
