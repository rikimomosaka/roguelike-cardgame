## 1. 方針

ストライカーに 3 人を置き、「ターン中に何を達成すると強いか」を変えて差別化する。

| | A（セラ、実装済み） | B（追加予定） | C（将来） |
|---|---|---|---|
| 方向性 | コンボを伸ばす → 残光 | 静で溜め、動で大量に使う | コンボを抑える |
| 一言 | コンボを完成させる | カードを使い切る | コンボを捨てて強くなる |

コンボ・位相・双極・終撃はストライカー共通の仕組み。各キャラは「それを最も効率よく扱える」立ち位置にする。

## 2. 決まったこと（2026-11-27）

- **転相共鳴**（位相を新たに得るたびにコンボゲージ+1）: キャラの特性にはしない（強すぎる）。エピックかレジェンダリーのパワーカードにする。
- **転相**（B の戦技案、ゲージ 1）: ただの反転。位相なしのときは何も起きない（無から静にする効果は付けない）。今の `invertPhase` で作れる。
- **零式**（コンボ 0 で追加効果のキーワード）: カードのキーワードとして作るかは保留。
  代わりに **C に「コンボ 0 のときに使うカードのコストを軽減する」能力**を持たせる案を有力として検討する。
  - 今のコンボ規則（続けるとコスト−1）の対になる: A は続けて得をし、C は区切って得をする。
  - 終撃でコンボを 0 に戻すと次の 1 枚も対象になる（相性は良いが、強さの調整点）。
- **双極は常に 1 つ**（実装済み、[current-phase-spec.md](current-phase-spec.md) §2）。
- **カードは当面設計だけ**。キャラごとに順番に、どんなカードを作るかを考える。

## 3.5 B の決定（2026-11-28、実装済み）

B は **転相拳士シオン**（`striker_shion`）。特性・戦技・奥義・初期デッキは [current-characters-and-class-cards.md](current-characters-and-class-cards.md)。
静の「受けるダメージ軽減」は B の特性ではなく、静の位相そのものの効果にした（[current-phase-spec.md](current-phase-spec.md) §1.2）。奥義は仮置きで、あとで再設計する。
