# 現行カードコスト仕様

> 更新日: 2026-08-10  
> 本文書はカードコストに関する旧Phase文書より優先する。

## 2種類のコスト

- **元コスト**: 強化状態を反映したカード定義上のコスト。コンボの連鎖判定と`LastPlayedOrigCost`には必ずこの値だけを使う。
- **現在コスト**: 実際に支払う値。個別カードの変更、手札限定status、コンボ軽減を順に反映し、0未満は0へ丸める。

現在コストが0でも、元コスト1のカードの次に元コスト2のカードを使えばコンボは継続する。現在コスト同士の0→0はコンボ判定に使わない。

画面では現在コストを左上から張り出す`28×28px`の配置箱へ置き、所属別コスト台座画像だけを中央基準で`30×30px`へ広げ、20pxの数字を中心から2px上へ補正して表示する。拡大後の台座とカード名が重ならないよう、表示全体は従来位置から1px左へ置く。現在コストが元コストより低い時は黄色、高い時は青色、同じ時は白色にする。現在値と異なる場合だけ、同じ所属の`22×22px`台座と13pxの元コストを、中心を揃えて現在値の直下へ追加する。元台座は現在値の配置箱の上端から27pxに置いて台座の実画素同士をほぼ接触させ、数字を中心から1px上へ補正する。元コストは「コンボが参照する数字」でもある。

継続バフを消費せずにコンボを継続できるカードは、コスト台座の色ではなくカード外周を包む半透明の金色オーラが明滅・拡縮するパルスで示す。継続バフの消費が必要な場合は実際にコンボが続いてもオーラを出さない。動きを減らすOS設定では、半透明の静止外周へ切り替える。

## 計算順

1. 強化状態を反映した元コストを求める。`null`ならプレイ不可。
2. 固定値変更（現在は`confusion`/混乱）があれば基準値を置き換える。この時点で、それ以前にカード個体へ付いていた加算式modifierは全て消去する。
3. カードInstanceの`CardCostModifier.Amount`を付与順に加算する。
4. 手札にあるカードだけ、heroの`handCostIncrease`（浪費）を加え、`handCostReduction`（節制）を引く。
5. 元コストが通常の連鎖条件を満たすか、直前のWild系保護があればコンボ軽減として1引く。
6. 0～`int.MaxValue`へ丸めた値を支払う。

この計算はCoreの`BattleCardCostCalculator`を唯一の規則とし、Serverは結果をDTOへ写し、Clientは再計算しない。

## コスト変更の内訳表示

固定値、カード個体modifier、手札限定status、コンボ軽減のいずれかが有効なカードは、詳細tooltipの右側へ計算順の内訳を表示する。最終的な現在コストが元コストと同じでも、途中に有効な変更があれば省略しない。

表示順はCoreが返す`CardCostBreakdown.Changes`をそのまま使う。Clientが差分から原因を推測したり、順序を組み替えたりしてはならない。

例: `コスト2 → [混乱]によりコスト3に変更 → 「手札整備+」によりコスト-1 → [節制]によりコスト-1 → コンボによりコスト-1 ＝ 0コスト`

混乱はカードが手札へ入った瞬間に0～3の固定値を決める。山札等で付いていた「手札整備」のような個別modifierはこの時点で消え、その後に新たに付与された個別modifierと、手札中に動的に作用する節制・浪費は固定値へ加算される。

## 個別カードの変更

`CardCostModifier`は加算式で、負数が軽減、正数が増加。複数効果は付与順に保持し合算する。

| 期限 | 未使用時 | カードを使用した時 |
|---|---|---|
| `UntilPlayed` | 領域・ターンを跨いで同じInstanceに残る | 失われる |
| `UntilTurnEnd` | 領域を跨いで残るがターン終了時に失われる | 失われる |

領域移動だけでは変更を消さない。山札、手札、捨札、除外、召喚保持、パワー領域のどこへ移っても同じカードInstanceに追従する。

カード効果`modifyCardCost`は次を使う。

- `amount`: signedのコスト増減値
- `pile`: `hand|draw|discard|exhaust`
- `select`: `all|random|choose`
- `cardCount`: random/chooseの対象枚数。省略時1
- `costDuration`: `untilPlayed|untilTurnEnd`

カード本文の自動翻訳は`[領域]の[選んだN枚／ランダムなN枚／全カード]のコストを[使用されるまで／ターン中]±X。`へ統一する。対象領域は`手札／山札／捨札／除外`とし、`amountSource: currentCost`だけは同じ主語・期限に続けて`0にする。`と表示する。

プレイ中のカード自身は、同じ効果による手札対象の候補から除外する。

## 手札全体へ作用するstatus

- `handCostReduction`（節制/Buff）: 手札中の全カードの現在コストをstack分減らす。
- `handCostIncrease`（浪費/Debuff）: 手札中の全カードの現在コストをstack分増やす。

これはカードInstanceへ書き込まない。新しく手札へ来たカードには即時適用され、手札を離れたカードには即時適用されなくなる。個別カードmodifierはそのまま保持される。
両状態はターン終了で消えず、カードを実際に使用した時、そのカードの支払計算へ適用した後に各1減少する。

## 奥義

奥義は発動時の手札をsnapshotし、各カードへ「その時点のコンボ軽減前の現在コスト」と同じ量の負の`UntilTurnEnd` modifierを加える。そのため発動直後は0になるが、後から手札コスト増加statusを受ければ再び0より大きくなり得る。

発動後に引いたカードは対象外。同じターンに再発動できる場合は新しいmodifierを追加する。対象カードを使用すれば、他の個別変更と同じくそのカードの全コスト変更が失われる。
