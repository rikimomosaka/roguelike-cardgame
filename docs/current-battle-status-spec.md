# 戦闘中の状態変化仕様

この文書を状態変化の現行仕様とする。状態IDはセーブ、カード効果、自動翻訳、
コンテンツ管理画面で共通して使用する。

## 共通規則

- `X` はその時点の状態値を表す。実画面では`X`と代入後の数値を黄色で表示する。
- 状態の減少・消滅は「`[状態名]`が1減少する」「`[状態名]`が消滅する」と表示し、
  角括弧内の状態名も黄色で表示する。
- 「ターン終了時に`[状態名]`が1減少する」は、そのキャラクター自身の行動ターン終了時に1減少する。
- `strength` と `dexterity` を除く状態値は0以下を保持しない。
- デバフの新規付与は `resistance` で無効化できる。複数対象への付与は対象ごとに判定する。
- 同じ対象へ同じ種別の状態をまとめて付与する場合、1個の`buff`または`debuff`効果に
  `statusChanges`を並べられる。バフとデバフは同じ配列へ混在させない。
- `statusChanges`を持つデバフは1回の付与として扱う。`resistance`がある場合は
  耐性を1消費して、その配列に含まれるデバフを全て無効化する。
- アタックの攻撃側補正順は「基礎値＋筋力 → 脱力0.75倍 → 元気1.5倍」。
- コストの計算順は「元コスト／混乱値 → カード固有補正 → 手札全体の浪費・節制 → コンボ軽減 → 0以上へ丸める」。
- コンボ継続判定と `LastPlayedOrigCost` は、混乱や他のコスト変更ではなくカード定義の元コストを参照する。
- キャラクター上の状態アイコンは初回付与順で左から並び、新しく得た状態を右端へ追加する。

複数デバフのJSON例:

```json
{
  "action": "debuff",
  "scope": "self",
  "statusChanges": [
    { "name": "silence", "amount": 1 },
    { "name": "handCostIncrease", "amount": 2 },
    { "name": "exhaustion", "amount": 2 },
    { "name": "distress", "amount": 2 }
  ]
}
```

自動説明は「自身に沈黙1・浪費2・消耗2・動揺2を付与。」となる。
従来の単一状態用`name`+`amount`も後方互換として読み込めるが、
`statusChanges`との併記は禁止する。

## バフ

| 名前 | ID | 表示説明 | 実行タイミング・数値の意味 |
|---|---|---|---|
| 筋力 | `strength` | アタックで与えるダメージがX増加する。 | 永続加算値 |
| 敏捷 | `dexterity` | 得るブロックがX増加する。 | ブロック付与1回ごとの加算値 |
| 拡散 | `omnistrike` | 全ての攻撃を全体攻撃に変更する。ターン終了時に[拡散]が1減少する。 | 有効中は全攻撃を全体化 |
| バリア | `barrier` | アタックによってHPが1以上減る場合、そのダメージを無効化し、[バリア]が1減少する。 | ブロック計算後にHP減少が生じるヒットだけ消費 |
| 吸血 | `lifesteal` | アタックによって減らしたHPのX%を回復する。 | 実HP減少量を基準に回復 |
| 反射 | `reflect` | アタックを受けた時、攻撃元にアタックの回数分だけXダメージを返す(この際ブロックを無視する)。 | 1ヒットごと。完全ブロックやバリアでも正のアタックなら反射 |
| 節制 | `handCostReduction` | 手札のカードの使用コストをX軽減する。カードの使用時に[節制]が1減少する。 | ターンを跨いで保持し、全カードの使用1回ごとに1消費 |
| 元気 | `vigor` | アタックで与えるダメージが1.5倍になる。ターン終了時に[元気]が1減少する。 | Xは残りターン数 |
| 追撃 | `pursuit` | 攻撃直前に、「敵全体にXアタック。」を得て、[追撃]が1減少する。 | 攻撃予定がある時に1回発動。予定表示にも即時加算 |
| 再生 | `regeneration` | ターン開始時にHPをX回復し、[再生]が1減少する。 | 現在値だけ回復後に1減少 |
| 堅牢 | `fortify` | ブロックを最大Xまで次のターンに持ち越す。 | ターン終了時の表示ブロックを上限Xで保持 |
| 耐性 | `resistance` | デバフを無効化し、[耐性]が1減少する。 | 付与1回につき1消費 |
| 復活 | `revive` | 死亡時に1度だけHPをX回復し、[復活]が消滅する。 | 致死ダメージ直後に発動し全消費。最大HPを上限とする |
| 成長 | `growth` | ターン開始時に筋力Xを得る。 | 自身は減少せず毎ターン発動 |
| 洞察 | `insight` | ターン開始時にX枚追加で引き、[洞察]が消滅する。 | 追加ドロー後に全消費 |
| 加速 | `haste` | ターン開始時のエナジー回復量を+Xし、[加速]が消滅する。 | その開始時だけ現在値を回復量へ加算後に全消費。エナジーUIの次ターン回復量にも加算して表示 |
| 継続 | `continuity` | コンボ条件を満たさないカードを使った時、コンボを継続し、[継続]が1減少する。 | Wild等の別保護がない時だけ消費。コンボ軽減も有効だが金色のコンボ継続オーラは表示しない |
| 熟練 | `mastery` | ターン開始時にコンボゲージをX得て、[熟練]が1減少する。 | 上限10。現在値だけ得た後に1減少 |
| 残光 | `afterimage` | 自身の攻撃終了時、終撃によって保存された全ての効果を使用順にX回再実行し、[残光]が消滅する。 | 発動開始時のXを確定して先に全消費。終撃記録がなければ空打ち |
| 堅持 | `steadfast` | ターン終了時に消滅するブロックの50%を次のターンに持ち越す。ターン終了時に[堅持]が1減少する。 | 堅牢で保持されない残りBlockの半分を切り捨てで追加保持 |
| 護衛 | `cover` | アタックによって味方が受けるダメージを、自身のブロックで可能な限り防ぐ。ターン終了時に[護衛]が1減少する。 | 元対象Blockの後、Barrierより前に前衛側の護衛者からBlockを支払う |
| 守勢 | `defensiveStance` | 自身のブロックを使って敵のアタックを完全に防いだ時、コンボゲージを1得る。ターン終了時に[守勢]が1減少する。 | 1ヒットごと。護衛Blockで最後まで防いだ場合も対象 |
| 連環 | `comboCarryover` | ターン終了時、現在コンボを次のターンへ持ち越し、[連環]が1減少する。次のターンに最初に使用するカードは条件を問わずコンボを継続するが、コンボによるコスト軽減を受けない。 | 現在コンボとコンボ履歴だけを保持。直前元コスト・Wild状態はリセットし、専用の1回予約で最初のカードを継続 |
| 余韻 | `afterglow` | ターン終了時に減少または消滅する自身の他のバフが1つ以上ある時、それらを全て維持し、[余韻]が消滅する。 | 二値。実際に終了時減少を防いだ場合だけ消費し、発動消費型Buffは対象外 |
| 共鳴 | `resonance` | 自身のみに共鳴以外のバフが付与された時、付与された全てのバフを他の全ての味方に付与し、[共鳴]が1減少する。 | 付与group単位で1消費。伝播は再帰せず、伝播先不在・上限でも自己付与成立時に消費 |

## デバフ

| 名前 | ID | 表示説明 | 実行タイミング・数値の意味 |
|---|---|---|---|
| 脱力 | `weak` | アタックで与えるダメージが0.75倍になる。ターン終了時に[脱力]が1減少する。 | ヒットごとに切り捨て |
| 脆弱 | `vulnerable` | アタックで受けるダメージが1.5倍になる。ターン終了時に[脆弱]が1減少する。 | ブロック通過後ダメージへ適用 |
| 毒 | `poison` | ターン開始時にXダメージを受け、[毒]が1減少する。 | ダメージ後に1減少 |
| 浪費 | `handCostIncrease` | 手札のカードの使用コストをX増加する。カードの使用時に[浪費]が1減少する。 | ターンを跨いで保持し、全カードの使用1回ごとに1消費 |
| 猛毒 | `virulentPoison` | 毒によって受けるダメージがX倍になる。 | 毒ダメージを `毒×X` にする。付与は1スタックずつ |
| 停滞 | `stagnation` | コンボゲージが増えなくなる。ターン終了時に[停滞]が1減少する。 | 消費は可能だが新規獲得だけを停止 |
| 火傷 | `burn` | ターン開始時に現在HPのX%のダメージを受け、[火傷]が消滅する。 | 切り捨て。正のXなら最低1ダメージ、発動後全消費 |
| 灼痕 | `scorch` | [火傷]が消滅する時、代わりに[灼痕]が1減少する。 | 火傷ダメージ後、火傷を維持して灼痕を1消費 |
| 混乱 | `confusion` | カードが手札へ入った時、その使用コストを0～3のランダムな数値に変更する。ターン終了時に[混乱]が1減少する。 | 0/1/2/3を各25%。元コストは不変。再び手札へ入れば再抽選 |
| 呪縛 | `curse` | カードを使用した時に[呪縛]が1減少する。[呪縛]が消滅したターンはカードを使用できなくなる。 | 0にしたカードまでは解決し、以後のカードを禁止 |
| 束縛 | `bind` | アタックカードを使用できない。ターン終了時に[束縛]が1減少する。 | `CardType.Attack` を禁止 |
| 沈黙 | `silence` | アタック以外のカードを使用できない。ターン終了時に[沈黙]が1減少する。 | `CardType.Attack` 以外を禁止 |
| 封印 | `seal` | 戦技・奥義を使用できない。ターン終了時に[封印]が1減少する。 | キャラクタースキルを禁止 |
| 消耗 | `exhaustion` | ターン開始時にエナジーをX失い、[消耗]が1減少する。 | 0を下限として減少後、自身を1減少 |
| 動揺 | `distress` | カードを使用することでコンボが途切れた時、エナジーとコンボゲージを0にする。ターン終了時に[動揺]が1減少する。 | 最初のカードは「途切れた」に含めない |
| 攪乱 | `disruption` | 自身の全てのアタックをランダム攻撃に変更する。ターン終了時に[攪乱]が1減少する。 | ヒットごとに再抽選。拡散と共存する場合は拡散を優先 |

## 決定性

- 混乱は既存の戦闘 `IRng` を使用し、手札へ入った順に1回ずつ抽選する。
- 追撃は独立した全体アタック1ヒットとして通常攻撃より前に解決する。
- 追撃の予定値は状態と現在行動から純粋計算し、表示のために乱数を消費しない。
