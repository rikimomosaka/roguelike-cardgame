# 位相（静・動）・双極・カードの後付け能力 現行仕様

最終更新: 2026-11-28
設計の経緯: [docs/superpowers/specs/2026-11-26-phase-and-card-augments-design.md](superpowers/specs/2026-11-26-phase-and-card-augments-design.md)

## 1. 位相

- バフ・デバフとは別の状態。全キャラ（主人公・味方・召喚・敵）が持ちうる。`CombatActor.Phase`（`None` / `Calm` / `Motion`）。
- 同時に持てるのは 1 つ。後から得た位相が上書きする。
- ターンをまたいで続く。消えるのは、別の位相を得たとき、「なしにする」効果、使用時の判定、戦闘終了（状態ごと破棄）。
- 反転: 静⇔動。位相がなければ何もしない。
- 主にストライカー向けだが、クラスや敵で制限しない。

### 1.1 使用時の判定

カードを使ったとき、効果を実行する前のその時点の位相で判定する（`PhaseRules.AfterCardUsed`）。
判定で決まるのは「消える予定」だけで、実際に消えるのはそのカードの効果処理が終わった後（`MarkExitOnUse` → `FinalizeCardPlay` の `ResolvePendingExit`）。

| 位相 | 使ったカード | 結果 |
|---|---|---|
| 静 | アタック | 位相なし |
| 動 | アタック以外 | 位相なし |

- 効果処理中に位相を得た場合（反転・同じ位相を得直した場合を含む）、消える予定は取り消される。
  例: 動でスキル「反転」→ 静で終わる。静でアタック「静にする」→ 静のまま。位相なしでスキル「動にする」→ 動。
- 効果で位相が変わらなければ、効果の後に位相なしになる（例: 静で普通のアタック → 効果の後に位相なし）。
- 「使用」に数えるのは実際のカード使用だけ。選択待ちの間は効果処理の途中なので消えず、再開して効果が終わってから消える。
- 敵（カード制御）は予約時ではなく、行動の再現実行で各カードの最初の効果を実行する前に 1 回判定し、その敵の行動が終わってから消す。戦場効果を持たない予約カード（ドローだけ等）は判定されない。

### 1.2 静のダメージ軽減（2026-11-28 改訂）

- 静のキャラが**アタックで受けるダメージを 0.75 倍**にする（毒・自傷などアタック以外のダメージは軽減しない）。
- 計算の位置は脆弱と同じ: ブロックで受けた残りに、脆弱 ×1.5 → 静 ×0.75 の順に掛け、各段で切り捨て（`DealDamageHelper.ApplyAfterBlock`）。
  例: 10 アタックを 4 ブロックで受けると 6 → 4。脆弱もあれば 6 → 9 → 6。
- 動（与えるダメージ 1.5 倍）と対になる、片方の位相だけで完結する効果。

旧仕様（〜2026-11-27）の「静でターンを終えると手札の全アタックに双極」は、位相の効果から外して
転相拳士シオンの特性（呼吸転換）にした（§1.2.1）。双極を付けるカードを取れば、他のキャラでも再現できる。

### 1.2.1 静のターン終了（特性）

- 手札を捨てる前に、静のキャラが「静でターンを終えた時」の特性（`OnCalmTurnEnd`）を持てば、その効果を出す（`PhaseRules.ApplyCalmTurnEnd`）。
  今これを持つのはシオンだけ（手札の全アタックに刻印【双極】）。
- 続く手札整理で、静の持ち主の双極付きカードは捨てられない（`BattleCardRetention.ShouldRetain`、双極の効果なので誰でも）。
- 画面用の予測（DTO の `retainsAtTurnEnd`）は、上の特性を持つ静の持ち主だけ、手札のアタックをまだ双極が無くても「残る」とする。
- 「動になった時」の特性（`OnMotionEntered`）は、setPhase・invertPhase で動になった時に出す。動から動への上書きでも出る（PhaseChanged は出ない）。

### 1.3 動のダメージ

- 攻撃を当てる瞬間（ターン終了時の攻撃解決）の位相で決まる。使ったときの位相ではない。
- 計算順（`AttackDamageMath.AdjustForAttacker`）: `floor((基本値 + 筋力) × 3/2)` → 脱力 ×3/4 → 元気 ×3/2（各段で切り捨て）。動と元気は重なる。
- 頭上の攻撃予告も同じ計算で、動のあいだは 1.5 倍で表示する。
- 既知の制限: カード制御の敵が「動になる」効果と攻撃を同じターンに予約しても、予告は現在の位相で計算する（予約中の位相変化は予告に反映しない）。

## 2. 双極

- キーワード ID `bipolar`、表示名「双極」。カードに後から付く（定義に最初から書くことは基本しない）。
- 何度付いても双極は 1 つ（2026-11-27。キーワードの上限 `CardKeywords.MaxCount` が 1）。
  2 以上に重ねる仕組み自体（カードごとの数の記録・「双極2」の表示）は残してあり、上限を変えれば戻せる。
  上限に達しているカードへの付与は何も起きない（付与のイベント・光る演出も出ない）。
- 静: 手札にある限り、次のターンに持ち越される（キーワード「待機」と同じ言い回し）。
- 説明文（静と動の間で改行）:
  「位相が静の時、手札にある限り、次のターンに持ち越される。／位相が動の時、発動時にエナジーを+Xする。／このカードの発動後、双極が消滅する。」
  X は表示する双極の数に置き換える（上限 1 のため現在は常に 1）。「X は○○の数」という説明はしない。
- 動: そのカードを使うと、エナジーを双極の数だけ得る（使ったキャラの参加者のエナジー。イベントの Note は `bipolar`）。
- 双極を持つカードを使うと、位相に関係なく双極はすべて消える（2026-11-27。動以外で使った場合エナジーは増えない）。
  双極を延々と増やし続けることへの歯止め。使わずに捨てられた・除外された場合は残る。
- 戦闘中はどの領域へ移っても残り、戦闘終了で消える。

## 3. カードの後付け能力

- `BattleCardInstance.Augments`（`CardAugment(Kind, KeywordId, Count)`）。今は `Kind = "keyword"` だけ。将来の刻印（カードに指定の能力を足す）もここに載せる。
- 同じキーワードは数を加算して 1 件にまとめる。コスト変更と同じくカード個体について領域を移動する。
- カードのコピー・生成では引き継がない。
- 同じキーワードを重ねられるかはキーワードごとの上限（`CardKeywords.MaxCount`）で決まる。双極は 1。
- 説明文: 定義のキーワードの後ろに後付けキーワードを足す。後付けは `[K:id|+]`、数 2 以上（上限の無いキーワードのみ）は `[K:id|+数]`。定義と同じ ID は合算。

## 4. カード効果

| action | 内容 | 項目 |
|---|---|---|
| `setPhase` | 位相を変える | `scope`・`side`、`name`: `none` / `calm` / `motion` |
| `invertPhase` | 反転 | `scope`・`side` |
| `augmentCards` | カードにキーワードを足す | `scope: self` のみ、`name`: キーワード ID、`amount`: 数、`pile`: `hand` / `draw` / `discard` / `exhaust` / `self`（このカード）、`select`: `all` / `random` / `choose`、`cardCount`、`cardTypeFilter`（例 `Attack`） |

- `augmentCards` の `choose` はカード選択待ちを使う（使用中のカード自身は候補から外す）。レリック等のトリガー効果では `choose` 不可。
- 文言: 「位相を静にする。」「敵単体の位相をなしにする。」「位相を反転する。」（反転はキーワード）
  「手札の選んだアタック1枚に刻印【双極】する。」「手札のランダムなアタック1枚に…」「手札の全アタックに…」「このカードに…」。
  双極は上限 1 なので、2 以上を付与する効果でも【双極】と書く（上限の無いキーワードなら【○○2】）。対象の言い方はコスト変更（modifyCardCost）と同じ。
- キーワード: 刻印（`enhance`、2026-11-28 に エンハンス から改名）「【 】内の能力をカードに刻む。」、反転（`invert`）「位相を持つ場合、対となる位相に変更する。」
- イベント: `PhaseChanged`（Note = `前->後:effect|used`）、`CardAugmented`（Note = `キーワード:後の数`）。

## 5. 画面

- オーラ: 体の輪郭に沿って揺らめく光（スプライトへの drop-shadow を周期的に変化）と、足元の輪。
  静 = 青くゆっくり（2.4 秒周期）、動 = 赤く速め（1.1 秒周期）。モーション設定 off で静止、reduced で周期 2 倍。
  一時的な発光や対象選択の光が出ている間はそちらを優先する。
- 足元の輪: 幅はキャラのドットの左右幅、下端はドットの下端に揃える（小さいキャラは小さく、浮いているキャラは浮いた足元に）。
  線は少しぼかしてドットになじませる。輪から光の粒が下から昇る（輪は体の後ろ、光の粒は体の手前に半透明で重ねる）。
- 静の間、キャラは動かない: 待機・被弾ののけぞり・奥義・カード使用のモーションをせず、目を閉じたコマ（still、セラは blink.png）で止まる。
  動くのは、静が解けるカードを使った時のモーション、攻撃の実行、ダウン。被弾の赤い点滅・ブロックの火花などの演出はそのまま。
  still を持たないキャラは立ち絵の静止画で止まる。
- 位相の説明文:
  静「アタックで受けるダメージが0.75倍になる。／アタックカードを使用した時、この位相は消滅する。」（2026-11-28 改訂）
  動「アタックで与えるダメージが1.5倍になる。／アタックカード以外を使用した時、この位相は消滅する。」
- 補足説明の位相の見出しは「静(位相)」「動(位相)」（位相名は青・赤、(位相) は白）。
- キャラにカーソルを合わせたときの説明の見出しは「特性：連閃」のように出す（戦技：・奥義：と同じ形）。
- キャラにカーソルを合わせたときの説明に、特性の後ろへ「位相：静／動」と効果を出す（特性が無いキャラは位相が見出し）。
  効果文中の双極はキーワードとして二段目に説明が出る。
- 位相が変わった瞬間は一時的な光を 1 回出す。
- カードに能力（双極など）が付く瞬間、そのカードが白く光り、光の途中で付与後の見た目に変わる（`CardAugmented` イベント、0.8 秒）。
- テキストの静・動は `[P:calm]` / `[P:motion]` で、青・赤で表示する。本文に静・動があれば、補足説明（二段目）に位相の効果を出す。
- 刻印で付いたキーワードはカード上で `[K:id|+]` / `[K:id|+数]` になり、文字のフチが紫になる（カード面・説明の両方、数字も含む）。数（○○2 の 2）は数字と同じ黄色。
- 能力値参照（攻撃の基本など）は、戦闘中のポップアップで「5(自身の攻撃力)」のように代入後の値を出す（カード面は「5アタック」、図鑑は「X(Xは自身の攻撃力)」のまま）。
- カードのキーワード行に「双極」。カード選択の見出しは「能力を付与するカードを選ぶ」。
- カードの説明ポップアップ: 本文は常にカーソル近く。用語の説明は横の別枠（本文の下端にそろえる、用語ごとに点線で区切る）。コスト変更の内訳は本文の上。

## 6. カード

ストライカー報酬カード（コモン、数値は仮）: 静水の構え（旧 静の型）、奔流の構え（旧 動の型）、静の太刀、烈火の踏み込み、流転の構え、返し刃、研ぎ澄まし、鎮めの一喝
（`src/Core/Data/Cards/striker_phase_*.json`）。各クラス・レア度 4 枚の報酬枠とは別に足している。
研ぎ澄ましの強化版は、双極の上限が 1 になったため「双極を 2 つ」から「コスト 0」に変えた（2026-11-27）。
転相拳士シオンの初期カード（Basic）: 静の型（スキル・4ブロック・静になる）、動の型（アタック・4アタック・動になる）（2026-11-28）。

## 7. 位相を扱うキャラの仕組み（2026-11-28）

- 特性の追加の発動条件（`trait.clauses`）: 1 つの特性に、別の契機・効果を足せる。使用回数は条件ごとに数える。
  契機に `OnCalmTurnEnd`（静でターンを終えた時）と `OnMotionEntered`（動になった時）を追加。
- 戦技・奥義の `requiresPhase`: 使用者が位相なしの間は使えない（画面のボタンも押せない）。
- 戦技・奥義の `phaseEffects`（`none` / `calm` / `motion`）: 使い始めた時点の位相で効果を選ぶ（共通の `effects` の後に実行）。
  説明文は「位相なし：…／静：…／動：…」の行で並べる。
効果と強化後の一覧は [current-characters-and-class-cards.md](current-characters-and-class-cards.md)。
