# 位相（静・動）・双極・カードの後付け能力 現行仕様

最終更新: 2026-11-26
設計の経緯: [docs/superpowers/specs/2026-11-26-phase-and-card-augments-design.md](superpowers/specs/2026-11-26-phase-and-card-augments-design.md)

## 1. 位相

- バフ・デバフとは別の状態。全キャラ（主人公・味方・召喚・敵）が持ちうる。`CombatActor.Phase`（`None` / `Calm` / `Motion`）。
- 同時に持てるのは 1 つ。後から得た位相が上書きする。
- ターンをまたいで続く。消えるのは、別の位相を得たとき、「なしにする」効果、使用時の判定、戦闘終了（状態ごと破棄）。
- 反転: 静⇔動。位相がなければ何もしない。
- 主にストライカー向けだが、クラスや敵で制限しない。

### 1.1 使用時の判定

カードを使ったとき、効果を実行する前のその時点の位相で判定する（`PhaseRules.AfterCardUsed`）。
判定で決まるのは「消える予定」だけで、実際に消えるのはそのカードの効果処理が終わった後（`MarkExitOnUse` → `FinalizeCardPlay` の `ResolvePendingExit`）。

| 位相 | 使ったカード | 結果 |
|---|---|---|
| 静 | アタック | 位相なし |
| 動 | アタック以外 | 位相なし |

- 効果処理中に位相を得た場合（反転・同じ位相を得直した場合を含む）、消える予定は取り消される。
  例: 動でスキル「反転」→ 静で終わる。静でアタック「静にする」→ 静のまま。位相なしでスキル「動にする」→ 動。
- 効果で位相が変わらなければ、効果の後に位相なしになる（例: 静で普通のアタック → 効果の後に位相なし）。
- 「使用」に数えるのは実際のカード使用だけ。選択待ちの間は効果処理の途中なので消えず、再開して効果が終わってから消える。
- 敵（カード制御）は予約時ではなく、行動の再現実行で各カードの最初の効果を実行する前に 1 回判定し、その敵の行動が終わってから消す。戦場効果を持たない予約カード（ドローだけ等）は判定されない。

### 1.2 静のターン終了

手札を捨てる前に、静のキャラの手札のアタック全てに双極を 1 付ける（`PhaseRules.ApplyCalmTurnEnd`）。
続く手札整理で、静の持ち主の双極付きカードは捨てられない（`BattleCardRetention.ShouldRetain`）。
画面用の予測（DTO の `retainsAtTurnEnd`）は、静の持ち主の手札のアタックをまだ双極が無くても「残る」とする（`RetainsAtTurnEnd`）。
これで残る札はターン終了の手札入れ替えで一度消えず、手札に残ったまま他の札が捨てられ、新しい札が入る。
主人公・副参加者・カード制御の敵のすべてに働く。

### 1.3 動のダメージ

- 攻撃を当てる瞬間（ターン終了時の攻撃解決）の位相で決まる。使ったときの位相ではない。
- 計算順（`AttackDamageMath.AdjustForAttacker`）: `floor((基本値 + 筋力) × 3/2)` → 脱力 ×3/4 → 元気 ×3/2（各段で切り捨て）。動と元気は重なる。
- 頭上の攻撃予告も同じ計算で、動のあいだは 1.5 倍で表示する。
- 既知の制限: カード制御の敵が「動になる」効果と攻撃を同じターンに予約しても、予告は現在の位相で計算する（予約中の位相変化は予告に反映しない）。

## 2. 双極

- キーワード ID `bipolar`、表示名「双極」。カードに後から付く（定義に最初から書くことは基本しない）。重ねると「双極2」「双極3」。
- 静: 手札にある限り、次のターンに持ち越される（キーワード「待機」と同じ言い回し）。
- 説明文（静と動の間で改行）:
  「位相が静の時、手札にある限り、次のターンに持ち越される。／位相が動の時、発動時にエナジーを+Xし、双極が消滅する。」
  X は表示する双極の数（双極2 なら 2、無印なら 1）に置き換える。「X は○○の数」という説明はしない。
- 動: そのカードを使うと、エナジーを双極の数だけ得て、そのカードの双極はすべて消える（使ったキャラの参加者のエナジー。イベントの Note は `bipolar`）。
- 位相なし: 何も起きない（普通に捨てられ、双極は残る）。
- 戦闘中はどの領域へ移っても残り、戦闘終了で消える。

## 3. カードの後付け能力

- `BattleCardInstance.Augments`（`CardAugment(Kind, KeywordId, Count)`）。今は `Kind = "keyword"` だけ。将来のエンハンス（カードに指定の能力を足す）もここに載せる。
- 同じキーワードは数を加算して 1 件にまとめる。コスト変更と同じくカード個体について領域を移動する。
- カードのコピー・生成では引き継がない。
- 説明文: 定義のキーワードの後ろに後付けキーワードを足す。数 2 以上は `[K:id|数]`（表示「双極2」）。定義と同じ ID は合算。

## 4. カード効果

| action | 内容 | 項目 |
|---|---|---|
| `setPhase` | 位相を変える | `scope`・`side`、`name`: `none` / `calm` / `motion` |
| `invertPhase` | 反転 | `scope`・`side` |
| `augmentCards` | カードにキーワードを足す | `scope: self` のみ、`name`: キーワード ID、`amount`: 数、`pile`: `hand` / `draw` / `discard` / `exhaust` / `self`（このカード）、`select`: `all` / `random` / `choose`、`cardCount`、`cardTypeFilter`（例 `Attack`） |

- `augmentCards` の `choose` はカード選択待ちを使う（使用中のカード自身は候補から外す）。レリック等のトリガー効果では `choose` 不可。
- 文言: 「位相を静にする。」「敵単体の位相をなしにする。」「位相を反転する。」（反転はキーワード）
  「手札の選んだアタック1枚にエンハンス【双極】する。」「手札のランダムなアタック1枚に…」「手札の全アタックに…」「このカードに…」。
  数が 2 以上なら【双極2】。対象の言い方はコスト変更（modifyCardCost）と同じ。
- キーワード: エンハンス（`enhance`）「【 】内の効果を与える。」、反転（`invert`）「位相を持つ場合、対となる位相に変更する。」
- イベント: `PhaseChanged`（Note = `前->後:effect|used`）、`CardAugmented`（Note = `キーワード:後の数`）。

## 5. 画面

- オーラ: 体の輪郭に沿って揺らめく光（スプライトへの drop-shadow を周期的に変化）と、足元の輪。
  静 = 青くゆっくり（2.4 秒周期）、動 = 赤く速め（1.1 秒周期）。モーション設定 off で静止、reduced で周期 2 倍。
  一時的な発光や対象選択の光が出ている間はそちらを優先する。
- キャラにカーソルを合わせたときの説明に、特性の後ろへ「位相：静／動」と効果を出す（特性が無いキャラは位相が見出し）。
  効果文中の双極はキーワードとして二段目に説明が出る。
- 位相が変わった瞬間は一時的な光を 1 回出す。
- カードに能力（双極など）が付く瞬間、そのカードが白く光り、光の途中で付与後の見た目に変わる（`CardAugmented` イベント、0.8 秒）。
- テキストの静・動は `[P:calm]` / `[P:motion]` で、青・赤で表示する。本文に静・動があれば、補足説明（二段目）に位相の効果を出す。
- エンハンスで付いたキーワードはカード上で `[K:id|+]` / `[K:id|+数]` になり、薄い黄色の蛍光ペン風の背景が付く。数（双極2 の 2）は数字と同じ黄色。
- 能力値参照（攻撃の基本など）は、戦闘中のポップアップで「5(自身の攻撃力)」のように代入後の値を出す（カード面は「5アタック」、図鑑は「X(Xは自身の攻撃力)」のまま）。
- カードのキーワード行に「双極」「双極2」。カード選択の見出しは「能力を付与するカードを選ぶ」。

## 6. カード

ストライカー報酬カード（コモン、数値は仮）: 静の型、動の型、静の太刀、烈火の踏み込み、流転の構え、返し刃、研ぎ澄まし、鎮めの一喝
（`src/Core/Data/Cards/striker_phase_*.json`）。各クラス・レア度 4 枚の報酬枠とは別に足している。
