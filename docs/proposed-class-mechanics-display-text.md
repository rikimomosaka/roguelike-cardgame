# クラス能力・表示文言 確認仕様

最終更新: 2026-08-21

この文書は、クラスカード作成前に、新規実装する用語とゲーム内表示文言を確定するための一覧である。

ここでいうクラス固有は配布上の方針であり、Coreの能力へクラス制限を設けない。同じ能力を別クラス、Universal、敵、メイト、レリック、ポーションへ設定することは技術的に可能にする。

## 1. 実装対象の総数

| 分類 | 数 | 対象 |
|---|---:|---|
| パラメータ付きカード能力 | 4 | 乗勢X、終撃、再演、伏策 |
| 新規バフ | 7 | 残光、堅持、護衛、守勢、連環、余韻、共鳴 |
| 新規デバフ | 1 | 攪乱 |
| 新規戦闘リソース | 0 | 調薬／備薬は不採用 |
| 既存能力の配布変更 | 4系統 | 直接回復、再生、復活、吸血 |

## 2. 共通の表示規則

- カード本文では能力名を短く表示し、詳しい処理はカーソルを合わせた用語説明へ出す。
- 数値とXは `[N:...]`、バフ・デバフ名は `[S:id]`、カード能力名は `[K:id]` で出力し、黄色の強調対象にする。
- 説明中に同じ用語が複数回出ても、同じ用語説明を入れ子で重複表示しない。
- 表示名に「Striker専用」などは付けない。所属クラスはカード外枠と取得プールで示す。
- 内部で既に存在する行動リプレイと混同しないよう、再演の内部IDには `replay` を使わない。

## 3. カード能力

### 3.1 乗勢X

- 表示名: `乗勢`
- 内部ID案: `momentum`
- 分類: 効果条件として働くパラメータ付きキーワード
- カード本文: `[K:momentum][N:X]：[条件成立時の効果]`

用語説明:

> 効果の実行時、自身のこのターンの最大コンボが[N:X]以上であれば適用される。

表示例:

```text
乗勢3：敵単体に11アタック。
```

補足表示:

- 成立中: `乗勢3：成立`
- 不成立: `乗勢3：不成立（最大コンボ2）`
- 実カード、残光、再演、伏策のいずれで効果を実行しても、その時点の最大コンボで再判定する。
- 既存の `comboMin` は現在コンボを参照する別条件であり、乗勢へ読み替えない。新規に `maxComboMin` 相当の条件を設ける。

### 3.2 終撃

- 表示名: `終撃`
- 内部ID案: `finisher`
- 分類: カード使用後のコンボ終了キーワード
- カード本文: `[K:finisher]`

用語説明:

> 効果の適用後、このカードを含むこのコンボ中の全てのアタックカードを残光としてこのターン中保存し、現在コンボを0にする。

表示例:

```text
敵単体に12アタック。
乗勢4：さらに8アタック。
終撃
```

補足:

- アタックだけでなく、そのアタックカードに含まれるブロック、バフ、デバフ、ドロー、選択なども保存対象になる。
- 保存するのは効果定義であり、元の対象、乱数結果、条件成立結果は保存しない。
- 条件付き部分は残光で実行する時点に改めて判定する。
- 終撃カードには原則として、十分なコンボを要求する乗勢効果を併記する。

### 3.3 再演

- 表示名: `再演`
- 内部ID案: `reprise`
- 分類: 条件付き効果再実行キーワード
- カード本文: `[K:reprise]：[検索条件]。`

用語説明:

> 再演条件を満たし、この戦闘中に最後に効果の解決を完了した自身のカード1枚の効果を再実行する。

表示例:

- `再演：3コスト以下のスキル。`
- `再演：アタック。`
- `再演：元コスト1のカード。`

補足:

- 元カードの終撃、伏策、喪失、待機、ワイルド、再演など、カード使用に伴うキーワードは再処理しない。
- 乗勢など効果部分の条件は再演時に再判定する。
- 選択式効果は再演時に改めて選択する。
- 再演された効果は「実際に使用したカード履歴」へ追加せず、再演から再演を再帰させない。

### 3.4 伏策

- 表示名: `伏策`
- 内部ID案: `contingency`
- 分類: 発動条件付きカードキーワード
- カード本文: `[K:contingency]：[発動条件]。`

用語説明:

> 使用時は効果が実行されず、発動待ちとして除外する。伏策条件を満たした時に効果を実行し、捨札へ移動する。

初期発動条件:

| カード本文 | 補足説明 |
|---|---|
| `伏策：ターン開始時。` | 伏策を仕込んだ後、最初に訪れる正式なターン開始時に発動する。 |
| `伏策：相手のアタック時。` | 敵のアタック1行動につき1回、追撃および最初のヒットより前に発動する。多段でも1回。 |
| `伏策：Xコンボ達成時。` | 自身の現在コンボがX未満からX以上へ到達した直後に発動する。 |

発動後表示:

- 通常: `発動後：捨札`
- 喪失あり: `発動後：除外`

除外ゾーンでの表示:

- カード上部に `伏策待機中` の帯を表示する。
- その下へ `ターン開始時`、`相手のアタック時`、`3コンボ達成時`などの条件を表示する。
- クラス外枠、選択時の黄色枠、プレイ可能発光と混同しないよう、カード内側に青紫色のゆっくりした脈動と小さな伏策アイコンを表示する。
- 強化など除外内で完結する操作では発動待ちを維持する。別領域へ移動した瞬間に通常表示へ戻し、`「カード名」の伏策が解除された。`とログ表示する。
- 発動時には現在の強化状態の効果列を使う。

## 4. 新規バフ

カード上の付与文は、既存形式どおり `自身に[S:id][N:X]を付与。` とする。以下はカーソルを合わせた時の正式説明文である。

### 4.1 残光X

- 内部ID案: `afterimage`

```text
自身の攻撃終了時、[K:finisher]によって保存された全ての効果を使用順に[N:X]回再実行し、[S:afterimage]が消滅する。
```

補足:

- 各周回で対象、乱数、数量、乗勢などの条件を決め直す。
- 選択式効果は各周回で改めて選択する。
- X回分を開始前に確定するため、処理中に得た残光は現在の繰返しへ追加しない。

### 4.2 堅持X

- 内部ID案: `steadfast`

```text
ターン終了時に消滅するブロックの[N:50]%を次のターンに持ち越す。ターン終了時に[S:steadfast]が[N:1]減少する。
```

計算は次の順で行う。

1. 堅牢で持ち越すブロックを確定する。
2. それでも失う予定のブロックの50%を堅持で追加保持する。
3. 両方を合計して次ターンへ持ち越す。

### 4.3 護衛X

- 内部ID案: `cover`

```text
アタックによって味方が受けるダメージを、自身のブロックで可能な限り防ぐ。ターン終了時に[S:cover]が[N:1]減少する。
```

補足:

- 元の対象のブロック、護衛者のブロック、元の対象のバリア、元の対象のHPの順に使う。
- 護衛者はHPやバリアではなくブロックだけを支払う。
- 1人目が防ぎ切れなければ、次に敵へ近い護衛者が残りを防ぐ。

### 4.4 守勢X

- 内部ID案: `defensiveStance`

```text
自身のブロックを使って敵のアタックを完全に防いだ時、コンボゲージを[N:1]得る。ターン終了時に[S:defensiveStance]が[N:1]減少する。
```

補足:

- 多段アタックは完全に防いだヒット数だけ発動する。
- 全体アタック1ヒットで同じ守勢保持者が複数人を護衛しても、その保持者の発動はそのヒットにつき1回までとする。
- 停滞中は既存規則どおりコンボゲージを得られない。

### 4.5 連環X

- 内部ID案: `comboCarryover`

```text
ターン終了時、現在コンボを次のターンへ持ち越し、[S:comboCarryover]が[N:1]減少する。次のターンに最初に使用するカードは条件を問わずコンボを継続するが、コンボによるコスト軽減を受けない。
```

補足:

- 現在コンボ数とコンボ内のカード履歴を持ち越す。直前の元コスト、Wild予約、Wild使用状態はリセットする。
- 次ターン最初のカードだけは専用予約でコンボを継続する。通常のターン最初のカードと同様にコンボ軽減は発生しない。
- 次ターンの最大コンボは持ち越した現在コンボ数から開始するが、その分のコンボゲージを再び得ることはない。
- 持ち越したコンボを終撃した場合、前ターンのアタックカードも残光記録へ保存する。

### 4.6 余韻

- 内部ID案: `afterglow`
- 二値バフ案。アイコン上の数値は表示せず、重複付与しても1を超えない。

```text
ターン終了時に減少または消滅する自身の他のバフが[N:1]つ以上ある時、それらを全て維持し、[S:afterglow]が消滅する。
```

補足:

- バリア、耐性、継続など、使用時に消費するバフは対象外。
- 再生、加速など、ターン開始時に消費するバフは対象外。
- 復活など、死亡時に消費するバフは対象外。
- 対象になるバフが複数あれば1回で全て維持する。

### 4.7 共鳴X

- 内部ID案: `resonance`

```text
自身のみに[S:resonance]以外のバフが付与された時、付与された全てのバフを他の全ての味方に付与し、[S:resonance]が[N:1]減少する。
```

補足:

- バフだけが対象。回復、ブロック、エナジー、カードコスト変更、デバフは対象外。
- 共鳴自身は全体化の対象外とする。復活を含む他のバフは対象にできる。
- 共鳴で広がった付与から、同じ付与連鎖中に別の共鳴を発動させない。
- 生存中の味方が本人しかいない場合や、他の味方が付与上限に達している場合も、本人へのバフ付与が成立した時点で共鳴を1消費する。

## 5. 新規デバフ

### 5.1 攪乱X

- 内部ID案: `disruption`

```text
自身の全てのアタックをランダム攻撃に変更する。ターン終了時に[S:disruption]が[N:1]減少する。
```

補足:

- 元が単体、ランダム、全体のいずれでも、攪乱中はランダムになる。
- 拡散があれば最終的に全体攻撃になる。
- アタックではない毒、火傷、反射、自傷などには影響しない。
- 予定行動表示も実効範囲へ即時更新する。

## 6. 既存能力の配布変更

以下は戦闘処理・表示文言とも既に実装済みであり、新しいクラス制限をCoreへ追加しない。

| 能力 | 現在の表示文言 | 配布方針 |
|---|---|---|
| 直接回復 | `味方単体のHPをX回復する。` | 通常のBasic／Rewardカードは原則Enhancer。ポーション・レリックは例外。 |
| 再生 | `ターン開始時にHPをX回復し、再生が1減少する。` | 通常カードは原則Enhancer。ポーション・レリックは例外。 |
| 復活 | `死亡時に1度だけHPをX回復し、復活が消滅する。` | 通常カードは原則Enhancer。Enhancerから他の味方へ付与可能。ポーション・レリックは例外。 |
| 吸血 | `アタックによって減らしたHPのX%を回復する。` | 原則敵専用。プレイヤー用通常カードと吸血付与レリックから外す。 |

休息・イベントなどの戦闘外回復は、クラス能力ではないため対象外とする。

現在の仮カードデータでは、再生・復活・吸血を持つStrikerカードが残っている。全クラスのカードを本制作する段階でEnhancerへ再設計するか、別効果へ置き換える。

## 7. 表示以外に必要な共通実装

| 基盤 | 主に使う能力 |
|---|---|
| カード使用を発生させず、効果列だけを実行・中断・再開する共通executor | 残光、再演、伏策 |
| Resolving中も本人の選択だけを受け付ける汎用pending choice | 残光、伏策、再演 |
| participant別の実カード使用履歴、現在コンボ履歴、最後の終撃記録 | 終撃、残光、再演、連環 |
| パラメータ付きカード能力schema | 乗勢X、再演条件、伏策条件 |
| 全カード領域移動を一元化し、除外外への移動で伏策待機を解除する処理 | 伏策 |
| ターン開始、敵アタック直前、コンボ到達のtrigger scheduler | 伏策 |
| 対象ブロック→護衛ブロック→バリア→HPを記録する被ダメージ処理 | 護衛、守勢 |
| ターン終了時のバフ変化を事前計算して一括適用する処理 | 堅持、護衛、守勢、連環、余韻 |
| 全ての正の状態付与を通す共通pipelineと再帰防止ID | 共鳴 |
| 実効果を持つキャラクター特性／パッシブ基盤 | ターン開始時に堅持1を得るGuardian特性など |
| DTO・ゲーム表示・実績・管理画面・説明tooltip・リプレイへの投影 | 全項目 |

## 8. 実装前に最終確認する点

確定済み。表示文言と詳細挙動の間に未決事項はない。

次は既決事項として実装する。

- 堅持はブロック0、または堅牢だけで全ブロックを持ち越した場合も1減少する。
- 余韻は数値を表示しない二値バフとし、重複付与しても1を超えない。
- 連環は前ターンのコンボ内カード履歴を維持し、次ターンの終撃記録へ前ターンのアタックカードを含める。Wild状態と直前コストは維持しない。
- `伏策：Xコンボ達成時。`はX未満からX以上になった瞬間だけ発動し、既にX以上の状態で後から仕込んでも即発動しない。
- ターン開始時伏策は、開始時状態変化と死亡判定、エナジー回復、通常ドローの後、レリック・Powerの開始時効果より前に発動する。
- 攪乱はヒットごとに対象を再抽選し、拡散と共存する場合は拡散を優先する。短い用語説明には省略し、詳細tooltipへ表示する。
- 乗勢は残光・再演・伏策を含め、効果を実行するたびに現在の最大コンボで再判定する。
- 余韻は維持対象になる他のバフがない場合は消滅しない。
- 共鳴は本人への対象バフ付与が成立した時点で1減少し、伝播先がいない場合や付与上限でも消費する。
